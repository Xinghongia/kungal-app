# 2026-10-18 · 用户主页内容条目改为原生跳转（0.8.16 同批）

## 背景

排行榜作品条目跳浏览器的同类问题排查中，发现用户主页还有多处内容条目也在
拼站内 URL。虽然 `UserProfileScreen` 的 `onOpenWeb` 接到了 `openUrlOrPath`
（站内链接会被再转成原生路径），但绕了一圈 URL 字符串处理，且依赖
`openInternalPath` 的路径覆盖，不如直接回调稳。

## 改动

`ui/user/UserContentTabs.kt` 与 `ui/user/UserProfileScreen.kt`：

- 动态概览：作品 / 评分 / 资源三条入口改为 `onOpenWork` / `onOpenRating` /
  `onOpenResource` 原生长回调；
- 游戏库：作品条目改 `onOpenWork`；
- 收藏：收藏夹改 `onOpenCollection`，工具集改 `onOpenToolset`；
- Galgame 标签：作品改 `onOpenWork`；
- 评分标签：改 `onOpenRating`；
- 工具集标签：去掉沿用 `onOpenWeb` 的默认值，只保留 `onOpenToolset`；
- 游玩时长：作品条目改 `onOpenWork`；
- `AppNav.kt` 的用户主页调用点改为直接 `nav.navigate(Routes.…)`。

现在用户主页所有内容条目都直接进原生详情页，不再经过 URL 字符串。
