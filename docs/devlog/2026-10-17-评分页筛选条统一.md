# 2026-10-17 · 评分页筛选条统一为资料库样式（0.3.1）

## 本批做了什么

- 驾驶员反馈「Galgame 评分页最上面的分类选项和资源资料库不一样，喜欢资料库那种，不要下拉」。
- 把评分列表页顶部筛选条改成与资源资料库完全一致：
  - 排序胶囊（排序图标 + 当前字段）+ 升/降序胶囊（箭头图标），排序字段为
    「最新 / 浏览最多 / 评分最高」，请求参数仍是 `created|view|overall × asc|desc`；
  - 剧透程度、游玩状态、游戏类型三枚筛选胶囊，点开是底部弹出的选项面板，
    不再是锚在胶囊下方的下拉菜单；
  - 有筛选或非默认排序时出现「清空」胶囊。
- 把 `FilterPill` 与底部选项面板从 `GalgameListScreen` 提取为共享组件
  （`FilterPills.kt`），资料库页与评分页共用同一套外观与交互。
- 主题页（话题列表）未改动。
- 版本 `0.3.0/code 3 → 0.3.1/code 4`，`USER_AGENT` 同步。
