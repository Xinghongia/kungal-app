## 导航设计（依据官方侧边栏 `apps/web/app/constants/layout.ts` 的 `kunSidebarRail`）

官方 Web 侧边栏四组（发布 / 话题 / Galgame / 其他）在手机竖屏放不下，
按「内容域」重组为 **底部五栏**，每个二级条目都有归属：

| 底栏 | 覆盖的官方条目 |
|---|---|
| 话题 | 全部话题（分类 chip：Galgame / 技术交流 / 其它）+ 发布 FAB |
| Galgame | 资料库(Galgame/数据库/评分)、发现(月历/情报/题库)、资源(资源列表/工具资源/网站资料库)、目录(会社/标签/角色/引擎/系列) |
| 发现 | 排行(话题/Galgame/用户)、动态(时间线/分类)、更新日志、帮助文档/友情链接/子网站 |
| 消息 | 通知与私信（BP-04） |
| 我的 | 账号概览 + 设置入口（顶栏齿轮，沿用 saku 约定） |

发布（官方"发布"组）为独立压栈页：发布话题 / Galgame / 工具 / 情报 / 习题。
二级页统一压栈并隐藏底栏；未交付功能进「开发中」占位页（标注排期 + 网页版入口，不伪造内容）。

## 完成内容

- **主题体系**（移植自 saku，MIT 自家作品）：6 套预设主题（新增**鲲蓝**为默认品牌色），
  动态取色（Android 12+，默认开）、深浅三态、纯黑模式、Material Expressive 动效、
  状态栏/导航栏图标跟随深浅。
- **设置页**：外观（主题模式/动态取色/主题色卡/纯黑）、浏览（话题默认排序，映射站点
  TopicSort）、数据（清图片缓存）、关于（版本/官网/开源地址/第三方免责声明）。
- **我的页**：未登录 = 登录入口；已登录 = 头像/昵称/UID/角色 chip/签到状态/萌萌点
  （数据来自 `/me`、`/me/account`，401 时自动清本地会话）；退出登录二次确认。
- **组件**：SettingsGroup（saku 移植）、KungalTopAppBar（透明融合顶栏）、HubScreen/HubContent。
- **core**：MeApi + Me/Account/ContentStance 模型 + 5 项单测（共 32 项全绿）。
