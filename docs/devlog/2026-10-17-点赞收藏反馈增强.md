# 2026-10-17 · 词条页点赞/收藏反馈增强（0.4.2）

## 本批做了什么

驾驶员反馈：Gal 词条页点赞和收藏点击后「没有一点变化」，看不出是否成功。

- 点赞按钮（`WorkDetailScreen.kt`）：
  - 未点赞：默认浅色 tonal 按钮 + 空心拇指；
  - 已点赞：按钮底色变主题色（primary）、文字与图标变 onPrimary、图标换实心拇指；
  - 统计小行里的拇指图标同步变实心并高亮。
- 收藏按钮：
  - 未收藏：默认浅色 tonal 按钮 + 空心心形；
  - 已收藏：按钮底色变错误色（error，与网页红心一致）、文字与图标变 onError、
    图标换实心心形；统计小行里的心形同步变实心红色。
- 操作成功提示：
  - 点赞成功 → 主题化提示「已点赞 / 已取消点赞」（`WorkDetailViewModel.toggleLike`）；
  - 收藏夹保存成功 → 「已收藏 / 已取消收藏」（`WorkDetailScreen` 的 `onSaved`）。

## 为什么之前看不出来

选中态只改了 16dp 小图标的颜色和「点赞→已点赞」一个字的差别，按钮底色完全没变，
所以肉眼几乎无法区分。本批把「按钮整体配色 + 图标实心/空心 + 统计行图标 + 提示条」
四层反馈一起加上。
