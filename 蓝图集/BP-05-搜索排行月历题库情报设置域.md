# BP-05 · 搜索、排行、月历、题库、情报与站务域

## 合同

把「发现页还是占位入口」补成网站同款的最后一组公共功能：

1. **全站搜索**：话题 / 回复 / 评论 / 用户 / 作品 / Galgame 留言墙 / 资料库实体 / 资源 / 工具集，
   「全部」聚合概览、搜索历史、关键词高亮、作品高级筛选。
2. **发售月历**：本月月历（按日）、未发售、年内待定、发售日期未定，同人开关。
3. **题库**：列表筛选排序、全部/我的答题、题目详情、单选/多选/判断作答、解析与剧透门禁、
   收藏、质量评分、评论墙、出题/编辑/删除、用户主页题库状态接线。
4. **情报**：情报/专栏列表、来源筛选、年月归档、详情（站内正文或原文链接）、首页情报流可选；
   我的投稿、新建/编辑/撤回、封面图上传。
5. **网站资料库**：分类分组的网站列表、搜索、分类/标签详情、网站详情、点赞/收藏、评论墙。
6. **站务与其他**：全站动态时间线（含分类筛选）、更新历史、待办列表、帮助文档（含目录）、
   友情链接、子网站导航。

排行榜与设置域已在 BP-04 交付，本蓝图不重做：

- `RankingScreen` 已有用户/话题/Galgame 三榜与网站全部排序项（BP-04 U5）；
- 设置域（外观主题、内容分级、通知偏好、云端偏好、资料/隐私设置）已在 BP-01/02/04 交付；
  账号中心的邮箱/密码修改属外部账号站，App 以浏览器打开，不自行实现。

- 范围来源：OpenAPI `search / rankings / release-calendar / quizzes / news-* / docs / friend-links /
  websites / website-categories / website-tags / update-logs / todos / activities` 组；
  web 页面 `pages/search|ranking|galgame-calendar|galgame-quiz|news|doc|friend-links|sites|
  website*|update|activity` 及 `components/search|ranking|galgame/calendar|galgame/quiz|news|
  doc|website|update|activity`。
- 不属于本蓝图：admin/版主管理面（网站/文档/友链/更新日志的后台创建入口，官方定位为非普通用户功能）；
  RSS 页面；账号中心自身页面；排行榜与设置域重做。
- 红线不变：不批量抓取（列表按页/游标加载，月历整月接口本身就是一次返回）；写操作复刻官方请求
  并带 `Idempotency-Key`（答题/出题/情报投稿等）；不绕过剧透门禁、不冒用官方身份；
  官方源码只读，不复制代码。

## 已核实事实（2026-10-17 OpenAPI + 匿名只读探测）

探测样本存 `research/probe/2026-10-17/bp05/`（gitignored）。除 `/me/*` 外全部匿名 200。

### 搜索（全部公开，GET）

- `GET /search/topics|replies|comments|users|works`：`q` 必填，`page`（1 起）+ `limit`；
  topics/replies/comments/works 支持 `include_nsfw`；返回统一分页 `total + total_relation`，
  网页 24/页。`works` 额外支持 `company_id / tag_ids / released_from / released_to /
  sort=LibraryWorkSort / exclude_tag_ids / exclude_tag_trees`；
  `LibraryWorkSort = relevance_desc（默认）| popularity_desc | released_desc |
  released_asc | updated_desc`。
- `GET /search/wall-comments`：`q` 至少 2 字，游标 `cursor` + `limit`（网页 24），无 total；
  命中带 `subject_type / subject_id / subject_path` 与可选 `work`。
- 资料库实体搜索复用现有实体接口的 `q`（标签/会社/引擎/系列/角色/Staff/特质），
  资源与工具集复用 `GET /galgame-resources?q=` 与 `GET /toolsets?q=`。
- 网页搜索页 tab：全部、Galgame、话题、回复、评论、用户、资料库（六类实体）、Galgame 资源、
  游戏评论（留言墙）、Gal 工具；「全部」预览量：话题 8、作品 12、资料库每类 8、资源 6、
  用户 8、回复/评论/工具/留言墙各 4。搜索框 400ms 防抖（Palette 300ms、1–107 字）；
  历史记录存本地、去重后置、最多 20，可单删/清空；高亮按空白拆词、忽略大小写。
- 跳转：话题 `/topic/{id}`（回复带 `?reply={floor}`，评论带 `?comment={id}`）、用户 `/user/{id}`、
  作品 `/galgame/{id}`、资源 `/galgame/resource/{id}`、工具 `/toolset/{id}`、
  实体 `/galgame/{tag|official|staff|series|engine|character}/{id}`；留言墙用 `subject_path`。

### 发售月历（公开）

- `GET /release-calendar?month=YYYY-MM`（省略=当前月）：`calendar_month / today_date /
  min_month / max_month / prev_month / next_month / has_prev / has_next / is_truncated /
  item_count / items[]`；作品字段含封面、名称、会社、发售日与精度、平台/语言、评分、浏览/赞。
- `GET /release-calendar/upcoming`：`entries[]` 按 `calendar_month` 分组；单月上限 500。
- `GET /release-calendar/pending?year=YYYY`、`/release-calendar/tba`、`/release-calendar/today`
  （`has_release / today_date / expires_in`，首页判断用）。
- 统一参数：`include_nsfw / include_doujin / exclude_tag_ids / exclude_tag_trees`；
  网页默认只显示日语原语言商业作品，同人开关 URL `doujin=1`；整月上限 2000 部。
- 网页 4 个 tab：`month`（默认）/`upcoming`/`pending`/`tba`；月历按日聚合、今日置顶高亮、
  `release_precision=month` 或无日期归入「本月内·日期待定」；空态与截断提示见网页文案。

### 题库（读公开；写需登录）

- `GET /quizzes`：`page/limit`（网页 50）+ `work_id / author_id / quiz_type / quiz_category /
  difficulty / spoiler_level / include_nsfw / sort=QuizSort`；`QuizSort` 16 个值
  （bumped_at / created / view / view_1d / view_7d / view_30d / difficulty / answer_count × asc|desc）。
  网页 UI 只暴露分类、题型、难度、排序字段与升降序。
- `GET /quizzes/{id}`：`Quiz` 含题面/描述 `ContentDocument`、选项、作者、统计、`works[]`、
  `is_work_hidden`、`viewer{has_answered,answer,has_favorited,quality_rating,can_edit,can_delete}`；
  `solution` 仅在已作答/作者/管理可见。
- 作答 `POST /quizzes/{id}/answers`（`Idempotency-Key` 必填）：单选/多选
  `{choice_indexes:[...]}`，判断 `{choice_indexes:[],is_statement_true}`；返回 `answer + solution`。
  作者自答 403 `SELF_ANSWER_FORBIDDEN`，重复作答 409 `ALREADY_EXISTS`（应重载题目）。
- 收藏 `PUT|DELETE /quizzes/{id}/favorite`；质量评分 `PUT /quizzes/{id}/quality-rating {rating:1-10}`
  （仅已作答后可见/可改）；作答记录 `GET /quizzes/{id}/answers`（游标 20，未解锁时
  `submission/is_correct=null`）。
- 评论墙：`subject_type=galgame_quiz`；剧透或隐藏作品且未作答时列表 403
  `QUIZ_ANSWER_REQUIRED`，网页提示「作答后即可查看并参与讨论」。
- 出题/编辑（登录即可，非管理）：`POST /quizzes`（`Idempotency-Key`）、`GET /quizzes/{id}/source`、
  `PATCH /quizzes/{id}`、`DELETE /quizzes/{id}`（`viewer.can_edit/can_delete`）。
  字段：`work_ids≤20 / is_work_hidden / quiz_type（创建后不可改）/ prompt_text≤200 /
  description_markdown≤20000 / choices 2–20 且唯一、各≤200 / correct_choice_indexes /
  is_statement_true / quiz_category / difficulty 1–10 / spoiler_level / explanation_markdown≤2000`。
- `GET /me/answered-quizzes?page&limit`（登录）供「我的答题」与用户主页答题 tab。
- 常量：题型 single 单选 / multiple 多选 / judge 判断；分类 plot 剧情 / character 角色 /
  system 系统 / music 音乐 / voice 声优 / company 会社 / trivia 常识 / other 其他；
  剧透 none 无剧透 / portion 部分剧透 / serious 严重剧透；
  难度 ≤2 入门、≤4 简单、≤6 普通、≤8 困难、其余地狱。

### 情报（读公开；投稿需登录）

- `GET /news-items`：游标 `cursor` + `limit`（网页 20，≤50），`include_total`、`lane=news|column`、
  `news_source`、`year`、`month`；返回 `total`（可选）与 `next_cursor`。
- `GET /news-sources`：来源全量（`key / display_name / attribution / homepage_url / column_url /
  forum_account`）。
- `GET /news-archive[?lane][&news_source][&year]`：不传 year 只回年份计数；传 year 回该年月计数。
- `GET /news-archive/{year}/{month}`：`days[]` 每日计数；`.../items?page&limit&day` 页码式列表。
- `GET /news-items/{id}`：详情 `banner / preview / content(ContentDocument) / source_url /
  published_at / submitter`；`has_body=false` 时站内无正文，只能跳原文。
- 投稿：`GET /me/news-submissions`（游标）、`POST /me/news-submissions`（`Idempotency-Key`）、
  `PATCH /me/news-submissions/{id}`（改为 `state:"withdrawn"` 撤回）；
  封面 `POST /me/news-submission-images`（multipart，JPEG/PNG/WebP ≤4MB，30 张/账号/UTC 日）。
  字段：`title / preview / content_markdown / source_url / banner_image_hash`；正文与链接至少一项。
  状态：pending 待审核 / published 已发布 / rejected 未通过 / withdrawn 已撤回。
- 网页标题、预览 ≤200，正文 ≤20000，链接 ≤1024 且 http(s)。

### 网站资料库（读公开；点赞/收藏/评论需登录）

- `GET /websites`：游标 + `limit`、`include_total`、`include_nsfw`、`website_category_id`、
  `website_tag_id`；摘要含 icon/external_icon_url/title/host/description/score/state/category。
  实测 `total=69`；服务端未按 score 排序（网页按分类分组、组内 score 降序、closed 单独「已关站」区）。
- `GET /websites/{website_host}`：完整字段 + `website_tags[]` + `viewer{has_liked,has_favorited,
  can_edit,can_delete}`；`state=normal|unreachable|closed`。
- 点赞/收藏 `PUT|DELETE /websites/{host}/like|favorite`（返回计数与 viewer）。
- 分类 `GET /website-categories`（含 `website_count`，按 `sort_order`）、`.../{slug}`；
  标签 `GET /website-tags`、`.../{slug}`（含 `level`、`website_tag_group_id`）。
- 评论墙 `subject_type=website`，与题库共用 `WallCommentApi` 与已读/关注接口。
- 普通用户不能创建/编辑/删除网站（需 `website.create/edit/delete`，属于 admin 面，不做）。

### 站务与其他

- `GET /activities`：游标 + `activity_types[] / topic_sections=normal|help|all / sort=
  occurred_desc|bumped_desc / include_nsfw / include_galgames_without_resources`；
  网页全站时间线 50/条、首页 30/条；条目带 `path`、类型、执行者、时间、可选对象引用。
  22 种 `ActivityType`（话题创建/回复/评论/被推/最佳答案、Galgame 创建/编辑/PR/资源/评分/
  评论、题库/网站/工具集、待办、更新日志）。
- `GET /update-logs`：游标（默认 20）；`change_type` 10 种：feat 增加功能 / perf 性能优化 /
  fix 错误修复 / style 样式修改 / mod 功能更改 / chore 其它修改 / sec 安全提升 /
  refactor 代码重构 / docs 文档修改 / test 测试用例。
  创建/编辑/删除需 `update_log.*` 权限，属管理面，不做。
- `GET /todos`：游标 + `include_total` + `state=pending|in_progress|done|discarded`；
  `project=forum|patch`；含 author/claimer/completed_at/viewer。写操作（认领/完成）按 viewer
  权限；本 App 只读展示（普通用户写权限未核实，不在本批冒险执行）。
- `GET /docs`：游标 + `sort=position_asc|published_desc|views_desc` + `doc_category=
  galgame|notice|kun|other` + `is_pinned`；`GET /docs/{slug}` 返回正文与作者，
  每次读取 `view_count +1`。网页列表循环拉全（100/页），详情左侧分类树 + 右栏目录。
  编辑入口仅管理端（admin），不做。
- `GET /friend-links`：游标；`friend_link_category=official|galgame|others`；
  `state=normal|down`（已下线仍可点，显示红色标记）。
- 子站 `/sites` 为网页前端常量（补丁站、账号中心、表情包、导航站、开发文档），无 API；
  客户端按同一份事实清单本地展示，外链浏览器打开。

## 失败回退

- 搜索/月历/题库/情报/网站接口若线上与 OpenAPI 不符 → 重新抓样本、更新夹具，不改范围；
- 题库出题/情报投稿等真实写操作用驾驶员账号验证前，先在沙盒/离线夹具验证请求构造；
- 文档正文出现未知节点 → 沿用现有 `ContentDocument` 渲染器的降级路径，不新增私有格式；
- 管理面能力（网站/文档/更新日志/待办写入）一律不做，避免权限与越权风险。

## 停止条件

- 普通用户权限与 OpenAPI 不符（例如题库出题需要额外权限）→ 带证据回驾驶员门；
- 发现必须绕过剧透/NSFW 门禁才能展示 → 停止，不绕过；
- 站点对客户端做出明确反制 → 停止并回门。
