# 2026-10-18 · BP-05 U5 情报阅读（0.8.7）

## 背景

BP-05 下一批 = U5：把网页 `/news`（Galgame 情报）从占位入口补成原生页面。
只读功能，全部匿名可浏览，不涉及账号写操作。

## 契约与样本

- OpenAPI：`/news-items`、`/news-items/{id}`、`/news-sources`、
  `/news-archive`、`/news-archive/{year}/{month}`、`/news-archive/{year}/{month}/items`。
- 网页行为：列表按 (发布日期, 来源) 分组（`apps/web/app/utils/news.ts` 的
  `groupNewsItems`）；栏目 = 全部/情报/专栏；来源与年份/月份可筛选；
  年月归档页按日筛选、50/页页码分页；转载条目的标题与「阅读原文」去对方站点，
  用户投稿 `has_body=true` 才进本站详情。
- 2026-10-18 匿名实测 10 个请求全部 200，样本存
  `research/probe/2026-10-18/news/`（gitignored）。实测时用户投稿总数为 0，
  因此详情样本为转载条目（正文空文档 + 原文链接）；正文渲染沿用现有
  `ContentDocumentView`。

## 改动

### core

- 新增 `NewsItem`（列表与详情共用，详情才有 `content`）、`NewsSource`、
  `NewsFeedPage`、`NewsArchive`（年/月计数）、`NewsMonth`（整月与逐日计数）。
- 新增 `NewsApi`：items（游标 + 可选总数）/ sources / archive / month /
  monthItems（页码分页）/ item。
- 真实样本夹具 7 份（`core/src/test/resources/fixtures/news_*.json`），
  `NewsApiTest` 7 项（路径、参数、解析、月/年计数、详情）。

### app

- `NewsUi.kt`（纯函数）：`newsGroups`（日期+来源分组）、`newsDate`、
  `newsTarget`（详情 / 原文 / 不可点）、`newsRows`（月份页扁平化）。
- `NewsViewModel.kt`：情报流游标累积 + 加载更多 + 失败重试；同一筛选不重复请求。
- `NewsScreens.kt`：
  - `/news` 总览：全部/情报/专栏、来源、年份、月份筛选与清除；
    共 N 条情报；分组抬头（日期、相对时间、来源主页与署名）；
    卡片（横幅、专栏标签、导语、时间/来源、阅读全文/阅读原文）；触底自动加载 +
    「加载更多」；末尾「情报来源」卡片。
  - `/news/{year}/{month}` 月归档：月份切换、按日筛选、整月/按日条数、
    50/页页码分页、分组列表。
  - `/news/{id}` 详情：横幅（按原图比例）、专栏/来源、标题、投稿人与时间、
    导语、`ContentDocumentView` 正文、原文链接与署名。
- 导航：`Routes.NEWS / NEWS_DETAIL / NEWS_MONTH`；站内路径 `/news`、
  `/news/{id}`、`/news/{year}/{month}?lane=&source=` 进原生；通知路径识别
  `/news/{id}`；Galgame 页与发现页「网站动态」入口接通。
