# 2026-10-17 · BP-02 U6 投稿与我的提交（0.4.0）

## 本批做了什么

BP-02 Galgame 资料库域的最后一个批次，对应网页：

- `/edit/galgame/publish`（发布向导，先搜索查重）
- `/edit/galgame/create`（四步新建申请表单）
- `/edit/galgame/mine`（我的提交）

### core

- 新增 `SubmissionApi`：
  - `GET /work-submission-candidates`：按名称搜索资料库，带 `include_nsfw` 与游标；
  - `GET /me/work-submissions`：我的投稿（`state` 逗号分隔、`include_total`、游标）；
  - `POST /work-submissions`：新建申请，必带 `Idempotency-Key`，保留响应
    `Location` / `ETag`；
  - `GET /work-submissions/{work_id}`：投稿详情与 ETag；
  - `PATCH /work-submissions/{work_id}`：送审 / 撤回 / 审核状态；`If-Match` 并发控制；
  - `DELETE /work-submissions/{work_id}`：删除草稿（带 `If-Match`）。
- 新模型 `Submission.kt`：候选、摘要、详情、创建结果、状态事件（拒绝原因）、
  创建/修改请求体；`claimStateLabel()` 与网页徽章文案一致。
- `KungalClient.deleteNoBody()` 支持自定义请求头（删除草稿的 If-Match）。

### app

- 发布向导（`SubmissionWizardScreen`）：
  - ① 搜索查重：输入任意语言名称，结果同时列出「你自己的待审核 / 已拒绝投稿」
    与资料库匹配作品；已有作品跳原生词条，他人待审条目提示「他人投稿审核中」；
    支持游标加载更多、NSFW 封面按内容姿态模糊。
  - ② 确实没有 → 「新建 Galgame 申请」，把当前搜索词带入简中标题（与网页一致）。
- 新建申请向导（`SubmissionCreateScreen` + `SubmissionCreateViewModel`）：
  - 四步：基本信息（英/日/简/繁标题、别名增删）→ 游戏介绍（四语言标签页）→
    分级元数据（SFW/NSFW、全年龄/R18、原始语言闭集、发售日期与 TBA）→
    预览图与提交；
  - 预览图走 `/work-edit-images`（preset=cover），成功后显示内容寻址预览；
  - 提交前确认；`409 DUPLICATE_SUSPECTS` 弹「资料库中已有同名作品」二次确认，
    确认后用新幂等键带 `is_duplicate_confirmed=true` 重发；
  - 响应 `state=live` 直接进词条，否则进「我的提交」；封面未挂上时如实提示。
- 我的提交（`MySubmissionsScreen`）：
  - 状态徽章（审核中 / 已拒绝 / 草稿）、提交与最后处理时间；
  - 已拒绝显示审核人、拒绝原因；
  - 按 `viewer` 能力显示：编辑（原生资料编辑页）、提交审核 / 重新提交、撤回、删除；
    撤回/删除有确认；每次写操作先读详情取 ETag 再带 `If-Match`。
- 入口接线：
  - 「发布」页的「发布 Galgame」→ 发布向导（未登录先登录）；
  - 「我的」页新增「我的 Galgame 投稿」；
  - 站内路径 `/edit/galgame/publish`、`/edit/galgame/create`、`/edit/galgame/mine`
    进 App。

  （`/work-submissions` 审阅者视角）不在 U6 蓝图范围内，未实现。
