# 2026-10-18 · 网页登录改为直达账号中心（0.8.17）

## 背景

驾驶员反馈：App 的「网页登录 / 注册」在部分手机上显示不全。点网站登录后弹出的
欢迎弹窗会落在屏幕最底部，按钮点不到；有的手机整页还会错位（当前这台 vivo
系统字体为 1.12 倍、屏幕宽 360dp，同样出现错位）。

原因有两层：

1. 旧实现加载 `https://www.kungal.com/` 首页，登录弹窗是网站自己的浮层；
   App 的 WebView 用默认配置，没有按站点 viewport 排版，部分机型会按错误宽度
   和缩放渲染，固定定位在底部的弹窗就被推出可视区。
2. WebView 文本会跟随系统字体缩放；字被放大后弹窗高度超出屏幕，底部按钮更容易
   被顶出可视区。键盘弹出时也没有避让。

## 改动

### core

`AccountAuthApi.kt`：

- 新增 `buildAuthorizeUrl(codes, prompt)`：生成账号中心 OAuth 授权地址，
  参数与站点前端一致（client_id / redirect_uri / scope / PKCE / state）；
- 新增 `exchangeAuthorizationCode(code, verifier)`：网页回调后复用现有
  `/api/auth/oauth/callback` 换 `kungal_session`；
- `oauthErrorMessage` 提为顶层函数，原生与网页登录共用；「需要额外验证」的
  提示从「请改用网页登录」改为「请在网页中完成验证后重试」，避免在网页登录页
  里让用户再改用网页登录。

### app

`LoginScreen.kt` 的 `WebLoginScreen`：

- 不再加载论坛首页，直接打开 NextMoe 账号中心的 OAuth 授权页；
  登录与注册都在账号中心完成，不再触碰论坛首页的底部弹窗；
- App 自己生成 PKCE；WebView 在 `shouldOverrideUrlLoading` / `onPageStarted`
  拦下 `https://www.kungal.com/auth/callback`，校验 state 后调用 core 换会话；
- 新增错误提示与「重新加载」；授权被拒绝、state 不符、网络失败都有中文提示；
- WebView 改为手机 Chrome 的渲染方式：`useWideViewPort` + `loadWithOverviewMode`
  + `textZoom = 100`；允许双指缩放作为极端机型的兜底；
- 内容区加 `imePadding()` / `consumeWindowInsets()`，键盘弹出时不遮住页面底部。

`OAuthCallback.kt`（新增）：只认站点注册的回调地址，解析 code / state / error。
