# 2026-10-17 · BP-04 / U2 我的菜单、积分与商店

## 本批交付

按 `蓝图集/BP-04-用户中心与消息域.md` 的 U2 范围，把「我的」页补成与网站头像菜单一致的
九项入口，并补上签到、萌萌点流水、商店与创作者申请。

### core（接口层）

- 新增 `ShopApi`：商品列表/详情、我的商店（余额/物品/装扮/订单/限购/到货提醒）、
  下单（`Idempotency-Key`）、装备/卸下（`/me/shop/loadout/{scope}/{slot}`）、
  到货提醒订阅/取消（`/shop/offers/{id}/restock-alert`）。
- 新增模型 `model/Shop.kt`（`ShopOffer`/`ShopReward`/`ShopItem`/`ShopInventory`/
  `ShopOwnedItem`/`ShopOrder`/`ShopRedeemCode`/`ShopLoadoutSlot` 等）与
  `model/MeExtras.kt`（`MoemoepointEntry`、`CreatorStatus`/`CreatorEligibility`/
  `CreatorApplication`）。
- `MeApi` 扩展：萌萌点流水（游标分页、reason 筛选）、创作者状态、创作者申请
  （必带幂等键，服务端 201）。
- 新增 8 项单测（`ShopApiTest`）：商品分页、库存解析、下单幂等键与余额、装备/卸下、
  到货提醒、流水解析、创作者状态、申请提交。

### app（界面层）

- **「我的」页重排**（对齐网站头像菜单）：
  - 账号卡（头像/昵称/UID/角色/签到状态/萌萌点）点击进本人主页；
  - 我的：萌萌点（余额 → 流水页）、萌萌点商店、每日签到、个人主页；
  - 消息与创作：我的消息、私信、创作者申请、我的订阅；
  - 账号：账号切换（退出 → 官方网页重登）、编辑资料、设置、退出登录。
- **每日签到**：确认弹窗 → `POST /me/check-ins`（幂等键）→ 提示获得点数并刷新；
  今日已签到只展示状态、不重复提交；服务端 `ALREADY_EXISTS` 显示「今天已经签到过了」。
- **萌萌点页**：余额卡、规则说明、收支流水（游标分页）；流水 reason 由机器码
  按网页 `MoemoepointLog` 规则翻译成中文（如 `content_approved` + `topic` →
  「创建了新的话题」），来源显示账号中心/其他站点，有 `ref_path` 的可点开网页。
- **商店页**：商店 / 我的物品 / 订单三个标签。
  - 商品按「本站专区 / 福利兑换 / 功能解锁 / 装扮 / 其他」分区；显示价格、时长、
    限购、库存、截止时间；余额不足/限购/售罄时按钮给出原因；售罄可订到货提醒。
  - 购买前二次确认（显示当前余额与买后余额）；成功后如有兑换码弹窗展示，
    点击复制；余额与库存自动刷新。
  - 我的物品：显示来源、有效期与装备状态；头像框/主页背景可选择
    「全站展示 / 仅本站」装备，可卸下。
  - 订单：奖励名称、价格、时间、状态与兑换码（点击复制）。
- **创作者申请页**：已是创作者的状态、最近一次申请（审核中/通过/未通过+原因）、
  四项资格进度（任意一项满足即可）、申请说明输入与提交确认。
- **账号切换**：确认后退出当前会话并跳转网页登录，登录完成回到原来的页面。
