# 2026-10-18 · BP-05 U8 动态、更新日志与待办（0.8.11）

## 背景

蓝图 U8：把发现页里的「动态时间线 / 分类动态 / 更新历史 / 待办列表」四个占位
换成原生页面，数据全部来自站点公开接口，写操作不在 App 开放。

## 改动

### core

- `FeedActivity` 扩展为完整动态模型：`excerpt_markdown`、`reply`、`comment`、
  `work`、`work_digest`、`work_stats`、`work_revision`、`galgame_rating`、
  `resource`、`quiz`、`toolset`、`todo`、`update_log`（按 `activity_type`
  只有一个详情块非空）。
- 新增 `UpdateLogApi`（`GET /update-logs`，游标分页）、`TodoApi`
  （`GET /todos`，游标分页 + `state` 筛选 + `include_total`）、模型
  `UpdateLog` / `Todo` / `TodoPage`。
- 真实样本夹具：`activities.json`（20 条混合类型，2026-10-18 匿名实测）、
  `update_logs.json`（20 条）、`todos.json`（20 条 / 总数 288）；
  `ActivityApiTest` 增加 2 项、新增 `UpdateLogApiTest` 2 项、`TodoApiTest` 2 项。

### app

- `/activity` 动态时间线：游标 50/页、触底加载、下拉刷新；卡片左侧发起人头像，
  按类型渲染话题封面/摘要、回复正文与引用、Galgame 封面与简介、评分、资源标签、
  题目、待办/更新日志；点卡片走 `openInternalPath` 进原生页面，点头像进用户页。
- `/activity/category` 分类动态：默认「新话题」，底部弹层按
  Galgame / 社区 / 工具集 / 站务 四组切换 22 种动态类型。
- `/update/history` 更新日志：游标 50/页，类型胶囊（增加功能/错误修复等）、
  日期与版本号、等宽字体保留换行正文。
- `/update/todo` 待办列表：状态筛选走服务端，项目（论坛/补丁站）在本地筛选；
  待办接口没有 project 参数，所以一次拉全（100/页，最多 20 页）后展示，
  页脚标明已加载数量；下拉刷新，只读展示待办内容、作者、认领人与状态。
- 导航：新增 `ACTIVITY`、`ACTIVITY_CATEGORY`、`UPDATE_HISTORY`、`UPDATE_TODO`
  路由；站内路径与发现页入口全部接原生，不再进占位页。
