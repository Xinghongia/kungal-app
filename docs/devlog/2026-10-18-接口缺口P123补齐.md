# 2026-10-18 · 接口缺口 P1 / P2 / P3 补齐（0.8.18）

## 背景

`docs/接口覆盖缺口-2026-10-18.md` 记录了普通用户面 42 个尚未接入的 operation。
驾驶员要求「先把 P1 P2 P3 做完」，本批一次补齐；P0（投票/抽奖作者侧）留待下一批。

## P1 · 用户主页「评论 / 点赞评论」

- core：`UserApi.wallComments(userId, relation, subjectType, cursor, limit)`
  → `GET /users/{id}/wall-comments`，复用 `WallCommentList`；
- app：用户主页 Galgame 标签筛选从「发布 / 贡献 / 点赞」扩为
  「发布 / 贡献 / 点赞 / 评论 / 点赞评论」；后两项走作品留言墙（游标分页），
  卡片显示评论正文、`评论于 Galgame #id`、时间与点赞数，点按进原生作品页。

## P2.1 · 标签多选联合筛选

- core：`GalgameEntityApi.taggedWorks(tagIds, page, limit, includeNsfw, …)`；
- app：Galgame 标签页新增「多标签筛选」：弹窗内搜索标签、勾选最多 10 个；
  选中后页面切换为「只看同时含有这些标签的 Galgame」，支持页码分页、
  顶部标签胶囊移除 / 清空 / 继续添加。

## P2.2 · 表情包选择器

- core：`StickerApi.packs()` → `GET /sticker-packs`，模型 `StickerPackList / StickerPack / Sticker`；
  新增 `stickerContentUrl()`（320 变体）与 `stickerMarkdown()`；
- app：新增共享 `StickerPickerDialog`（按包分页、四列网格）；话题编辑器「插入表情」把
  `![名称](…_320.webp)` 追加到正文；私信输入框新增表情按钮，选中后直接作为图片消息
  发送（`media.image_hash` = 官方图床 hash）；App 内缓存整包，一次进程只请求一次；
- 夹具 `sticker_packs.json` 为 2026-10-18 真实响应（202 KB）。

## P2.3 · @提及用户联想

- core：`UserApi.resolveUsers(q / ids, limit)` → `GET /users`，模型 `UserResolveList`；
- app：话题编辑器在正文末尾输入 `@关键词` 时，300ms 防抖查询用户并在输入框下方
  显示候选（头像 + 昵称）；点选后用 `@昵称 ` 替换正在输入的那一段。

## P3.1 · 关注分组展开

- core：`TopicApi.followingGroupItems(groupId, cursor, limit)` →
  `GET /activity-groups/{id}/items`；
- app：关注动态分组卡片在「共 N 条」处改为「查看全部 N 条」；展开后组内显示
  已加载条目，支持「加载更多」，失败就地提示。

## P3.2 · 题库收藏态批量查询

- core：`QuizApi.states(quizIds)` → `GET /me/quiz-states`，模型 `QuizStates / QuizState`；
- app：动态时间线与分类动态每加载一页，就对本页题目 id 批量查询收藏态；
  `galgame_quiz_creation` 卡片新增收藏心形，点击乐观更新、失败回滚并提示。

## P3.3 / P3.4 · 旧链接兼容

- core：`CollectionApi.alias(aliasId)` → `GET /collection-aliases/{id}`；
  `GalgameEntityApi.companyRedirect(wikiCompanyId)` → `GET /wiki-company-redirects/{id}`；
- app：收藏夹详情遇到 404 时先解析旧 id 再取新收藏夹，后续作品列表 / 编辑 / 删除 /
  移出全部使用解析后的 id；会社详情遇到 404 时先解析旧 wiki 会社 id 再加载详情与关系图。
