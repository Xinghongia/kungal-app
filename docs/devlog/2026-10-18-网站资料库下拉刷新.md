# 2026-10-18 · 网站资料库下拉刷新（0.8.10）

## 背景

驾驶员看过 U7 网站资料库后要求加下拉刷新。

## 改动

- 网站资料库四个页面接入应用现有的 `KungalPullToRefresh`（KunUI 萝莉指示器）：
  - `/website` 总览：重拉分类与全量站点列表；
  - `/website/{host}` 详情：重拉详情与标签/分组（注意：详情接口每次读取会让
    站点访问量 +1，刷新与网页打开页面行为一致）；
  - `/website-category/{slug}` 与 `/website-tag/{slug}`：重拉实体与该分类/标签下全部网站。
- 刷新期间保留当前内容、不切回整页 Loading；刷新失败只弹主题提示，原列表不丢；
  首次加载失败仍显示整页错误与重试。
- 刷新期间重复下拉会被忽略。

- `assembleDebug` 通过；版本 `0.8.9/code 38 → 0.8.10/code 39`，
  `USER_AGENT` 同步为 `kungal-app/0.8.10 (Android)`；
- APK 已装机（0.8.10/code 39），启动冒烟无崩溃。
