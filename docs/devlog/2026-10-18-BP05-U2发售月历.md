# 2026-10-18 · BP-05 U2 发售月历（0.7.6）

## 背景

Galgame 页「发售月历」入口此前是占位页，打开只能跳网页。本批把网页
`/galgame-calendar` 的四个视图做成原生页：月历、未发售、年内待定、发售日期未定。

## 接口（2026-10-17 OpenAPI + 匿名探测，样本在 `research/probe/2026-10-17/bp05/`）

- `GET /release-calendar?month=YYYY-MM`：整月返回
  `calendar_month / today_date / items[] / prev_month / next_month / has_prev / has_next /
  min_month / max_month / item_count / is_truncated`；省略 month = 当前月（日本时间），
  整月上限 2000 部。
- `GET /release-calendar/upcoming`：`entries[]` 按月分组（从当前月到 max_month，最多 24 个月，
  单月上限 500），`item_count` 为总作品数。
- `GET /release-calendar/pending?year=YYYY`：只知年份、月份待定；省略 year = 当前年。
- `GET /release-calendar/tba`：发售日期未定。
- `GET /release-calendar/today`：`has_release / today_date / expires_in`，首页判断用；
  该端点不接受同人开关。
- 统一参数：`include_nsfw / include_doujin / exclude_tag_ids / exclude_tag_trees`；
  网页默认只显示原语言为日语的商业作品，`doujin=1` 才加入同人社团作品。
- 作品条目复用现有 `WorkSummary` 模型，字段与资料库列表一致。

## 实现

- core：`ReleaseCalendarMonth / Upcoming / Pending / Tba / Today` 五个模型与 `CalendarApi`
  五个方法；真实响应样本作为夹具（4 份月历样本 + today）。
- app：
  - `CalendarViewModel` 管理四视图与同人开关；每个视图按当前参数缓存结果，切 tab 不重复请求；
    内容姿态、同人开关或标签屏蔽变化时清空缓存重取；
  - `/galgame-calendar` 原生页：
    - 月历：月份切换（前后月/回到本月）、周日起始 7 列网格、每日作品数角标、今日高亮、
      点击日期滚动到当日分组；今日有作品时置顶，其余按日升序；日期精度为月或无发售日的
      作品归入「本月内 · 日期待定」并排在最后；截断提示与空态；
    - 未发售：按月份分组、每月数量与截断提示；
    - 年内待定：年份前后切换、数量统计；
    - 发售日期未定：数量统计、空态与截断提示；
    - 作品卡与资料库一致（两列、NSFW 封面打码跟随内容姿态），点按进原生词条页。
  - 标签屏蔽沿用 `/me/blocked-tags`（exact → `exclude_tag_ids`，其余 → `exclude_tag_trees`）。
  - Galgame 页「发售月历」入口改为原生；`/galgame-calendar` 站内路径接入，并解析网页分享
    链接的 `view / month / year / doujin` 参数。
