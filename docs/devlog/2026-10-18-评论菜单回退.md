# 2026-10-18 · 评论三点菜单回退为标准下拉（0.8.5）

## 背景

修「三点菜单从左侧弹出」时，我额外做了一个自绘的右对齐弹层（0.8.4），
实际显示成横跨大半屏的大菜单，观感很差。驾驶员要求回退。

## 改动

- 删除自绘的 `EndAnchoredMenu` 与定位器（0.8.4 引入）。
- 评论墙与话题楼中楼的三点菜单回退为 Material 3 标准 `DropdownMenu`，
  保留「放进按钮所在的 Box」这一修复（直接塞在整行 Row 里才会从行首弹出）。
- 0.8.3 的点赞/回复对齐与 0.8.1 的就地回复输入框不动。

## 证据

- `:core:test` 189 项、`:app:testDebugUnitTest` 96 项，合计 **285 项全绿**；
- `assembleDebug` 通过；版本 `0.8.4/code 33 → 0.8.5/code 34`，
  `USER_AGENT` 同步为 `kungal-app/0.8.5 (Android)`；
- APK 已装机（0.8.5/code 34）；驾驶员已确认效果。
