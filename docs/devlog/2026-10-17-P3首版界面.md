# 2026-10-17 · P3 首版界面

## 本日目标

app 侧首版界面：话题列表/详情/登录页（WebView 会话捕获）+ 正文树渲染 + 点赞/回复写通道
（蓝图 P3），退出条件 = 编译通过 + 静态产物 + 真机主路径。

## 完成内容

- **会话持久化**：`SessionStore`（DataStore 存 cookie）+ `KungalApp`（Application：客户端/接口/会话单例，
  `session` StateFlow 供界面观察）；MainActivity 启动恢复会话。
- **登录页**（`ui/login/LoginScreen.kt`）：App 内 WebView 打开站点首页走官方登录/注册
  （账号统一在 account.nextmoe.com）；**只观察站点自己种下的 `kungal_session` cookie**，
  不代填账号密码、不模拟登录请求；拿到即持久化并返回。网页内可后退。
- **正文树渲染**（`ui/content/ContentRenderer.kt`）：覆盖 blocks.go 全部 25 种块/行内节点——
  段落/标题/分隔线/引用/有序无序列表+任务框/代码块（等宽横滚）/公式（TeX 源码占位）/
  表格（对齐+表头加粗）/剧透块（点击显示）/行内剧透（点击显示）/粗斜删/行内代码/行内公式/
  换行/链接（可点）/图片（宽高比占位、贴纸小图、失败兜底）/视频（浏览器打开）/@提及/#楼层引用。
- **话题列表**（`ui/topic/TopicListScreen.kt` + VM）：keyset 游标分页（触底加载）、下拉刷新、
  封面 16:9 卡片、分类/版块/抽奖/NSFW chip、作者头像+时间+三计数、空态/错误/重试。
- **话题详情**（`ui/topic/TopicDetailScreen.kt` + VM）：头部（标题/chip/作者/浏览数）→ 正文树 →
  点赞（乐观更新 + 失败回滚，未登录引导登录）→ 回复列表（楼层号/最佳答案/置顶徽章、触底加载）
  → 底部回复框（Markdown 源文、幂等键 UUID、未登录引导登录）；打开详情上报浏览计数（失败静默）。
- 通用组件（`ui/components/Common.kt`）：图片兜底占位/头像圆形兜底/Loading/Error/Chip。
