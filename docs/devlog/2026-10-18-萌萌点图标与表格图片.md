# 2026-10-18 · 萌萌点图标与一行多图表格渲染（0.8.13）

## 背景

驾驶员实机反馈两处话题详情页问题：

1. 作者与回复者名字右边的萌萌点显示成 `@ 52`，网站用的是专用图标；
2. 正文里一行放三张图的 Markdown 段落在 App 里整块空白，网站正常显示。

## 根因

- 萌萌点：`TopicHeader` 与 `ReplyUi` 直接拼了 `"@ $points"` 字符串。
  网页用户卡片用的是一个 24×24 描边 SVG（放大镜轮廓里套 @ 弧线），
  并非字符 `@`。
- 一行多图：服务端把「同一行多个图片」的 Markdown 转成
  「一行多列的 `table`，每个 `table_cell` 里一个 `image` 节点」。
  `TableView` 原来把每个单元格交给 `appendInlines` 当纯文本渲染，
  而 `appendInlines` 没有 image 分支，图片节点被静默跳过，
  于是整张表只剩空单元格——看起来就是「什么都不显示」。

## 修复

- `ui/components/Common.kt`：新增 `MoePointIcon`（按站点 SVG 路径重绘的
  `ImageVector`）与 `MoePointBadge`（图标 + 数字，颜色取主题 secondary，
  对应网页的 `text-secondary`）。
- `ui/topic/TopicDetailScreen.kt`、`ui/topic/ReplyUi.kt`：作者/回复者
  萌萌点改用 `MoePointBadge`。
- `ui/content/ContentRenderer.kt`：`TableView` 拆出 `TableCellView`，
  单元格内按「文字段 + 图片段 + 视频段」混排（复用 `groupParts` 与
  `ImageBlock`），表头行仍加粗；单元格里有图片时不再被吞掉。
