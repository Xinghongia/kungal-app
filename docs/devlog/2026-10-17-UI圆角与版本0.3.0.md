# 2026-10-17 · UI 圆角统一与版本 0.3.0

## 本批做了什么

- 驾驶员反馈「长方形框框不好看，比如 Galgame 评分里的发布评论」，因此统一调整控件形状：
  - `Theme.kt` 新增全局 `KungalShapes` 并传入 `MaterialExpressiveTheme`：
    `extraSmall`（OutlinedTextField 的默认形状来源）从 Material 默认 4dp 提到 24dp，
    `small/medium/large/extraLarge` 也同步调大（20/24/28/32dp）；
  - 评论墙的评论输入框显式使用 22dp 圆角，发送按钮显式使用 pill（`RoundedCornerShape(50)`）。
- 这样全 App 的 `OutlinedTextField`（搜索、评论、私信、编辑表单等）都不再是接近直角的矩形。
- 版本号：`versionCode 2 → 3`，`versionName 0.2.0 → 0.3.0`（覆盖 BP-02 U1–U5 的功能批次），
  `KungalClient.USER_AGENT` 同步为 `kungal-app/0.3.0 (Android)`。

## 证据

- `:core:test` 134 项、`:app:testDebugUnitTest` 45 项全绿；`assembleDebug` 通过。
- APK 已装机，`dumpsys package com.kungal.app` 显示 `versionCode=3`、`versionName=0.3.0`。
- 未做逐页截图走查（按约定由驾驶员自测）。

## 已知边界

- 全局圆角只影响 Material 组件默认形状；页面里显式写死 `RoundedCornerShape(12.dp)` 的卡片维持原样，
  卡片不属于输入控件，未做改动。
- 若驾驶员觉得输入框还需要更圆（完全 pill），可把 `KungalShapes.extraSmall` 再调到 28–32dp。
