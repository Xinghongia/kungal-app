# BP-04 · 用户中心与消息域

## 合同

把「我的页只有账号概览」补成网站同款的用户中心：任意用户主页及全部标签、关注/粉丝、
资料设置（头像/昵称/签名/隐私）、头像菜单九项（积分/商店/签到/消息/私信/创作者申请/账号切换）、
通知中心、实时私信、排行榜。全部走站点官方接口，不绕过权限与萌萌点规则。

- 范围来源：`apps/web/app/pages/user/`、`pages/message*/`、`pages/messages/`、`pages/point/`、
  `pages/shop/`、`components/user/`、`components/chat/`、`components/kun/top-bar/UserInfo.vue`；
  OpenAPI `users / me / notifications / shop / rankings` 组 + 站点 chat relay（`/api/v1/chat/*`，
  契约以 `shared/types/chat.ts` 与线上实测为准，不在 OpenAPI 内）。
- 排序说明（驾驶员 2026-10-17 决定）：本蓝图**提前到 BP-02 之前**执行；BP-02/BP-03 顺延。
  用户主页里依赖 Galgame/资源/题库/工具集的标签先接真实只读列表，条目详情等对应域交付后接入，
  期间点条目跳网页——不删项。
- 不属于本蓝图：Galgame 词条详情与评分编辑（BP-02）、资源下载与工具集详情（BP-03）、
  全站搜索/月历/情报/文档（BP-05）；私信的 Centrifugo 实时通道属于 U5，REST 基础聊天属于 U4。
- 红线不变：不批量抓取；写操作带 `Idempotency-Key`（签到/下单/私信/申请）；改名/商店扣点
  必须显式确认；不做本地权限绕过；账号切换只走官方 OAuth 重登，不保存多份会话。

## 已核实事实（2026-10-17 只读探测）

- `GET /api/v1/users/{id}` 返回 `counts` 19 项（话题/投票/抽奖/回复/评论/作品/评分/资源/工具/
  被推/被赞/被踩/关注/粉丝…），`avatar_frame` 为 `{static_url, animated_url}`。
- 用户内容列表均为 page/limit（`relation` 必填）：topics `authored|liked|upvoted|favorited|hidden`、
  replies/comments `authored|received|liked`、works `published|contributed|liked`、
  resources `published|liked`、toolsets `authored|favorited`；游戏库为游标 + `state_counts`。
- 关注：`GET/PUT/DELETE /me/following/{id}`，`PATCH` 改通知档 `all|feed`。
- 资料：`PATCH /me/profile {name|bio}`（改名扣点，价格 `GET /account-prices`）、
  `PUT /me/avatar`（multipart，≤4MiB）；隐私三项：`/me/profile-settings`（仅登录可见）、
  `/me/privacy-settings`（游玩记录公开）、`/me/activity-settings`（动态隐藏）。
- 签到：`POST /me/check-ins`（必带幂等键），随机 0–7 萌点，重复返回 ALREADY_EXISTS。
- 商店：`GET /shop/offers`、`GET /me/shop`、`POST /me/shop/orders`（幂等键）、
  `PUT/DELETE /me/shop/loadout/{scope}/{slot}`、到货提醒 `PUT/DELETE /shop/offers/{id}/restock-alert`。
- 创作者：`GET /me/creator-status`（资格五项进度）、`POST /me/creator-applications`。
- 通知：`GET /me/notifications`（游标/`is_muted`/类型）、`/summary`、`PUT /read-marker`、
  `DELETE /me/notifications/{id}`、`GET/PUT /me/notification-preferences`。
- 私信（线上 `chatEnabled=true`）：`GET /api/v1/chat/state` 用会话 cookie 直连返回 200；
  端点组 `/chat/conversations`、`/chat/messages`、`/chat/updates`、`/chat/realtime-token`。
- 用户排行榜：`GET /rankings/users?sort=moemoepoint_desc|topics_desc|replies_desc|comments_desc|resources_desc`。

## 技术与证据要求

- core：所有新接口有离线单测（MockWebServer + 脱敏真实夹具）；私信契约按
  `shared/types/chat.ts` 建模，字段容错（新增字段忽略、缺失给默认值）。
- app：每批 `assembleDebug` 通过；写操作（资料、关注、签到、下单、私信）由驾驶员同意后验证。
- 证据四道门独立：automated / static-preview / real-host / driver；自动化不标 `driver-accepted`。
- 文档：每批更新 `NEXT.md` 与 `docs/devlog/`；线上残留（如有）必须列明。

## 失败回退

- `PROFILE_SIGN_IN_REQUIRED` / `PLAY_RECORDS_PRIVATE` → 按网页文案如实展示，不绕过。
- 改名/下单扣点前必须展示价格并二次确认；余额不足按服务端错误如实提示。
- 私信收到 `SCOPE_REQUIRED` → 提示重新走网页登录授权，不伪造会话。
- 实时通道不可用 → 降级为手动刷新 + 页面可见时 REST 同步，明确标注未连接。

## 停止条件

- 站点关闭 chat relay 或改为仅官方客户端可用 → 带证据回驾驶员门，讨论是否降级到旧私信。
- 出现需要绕过权限、批量抓取或冒用身份才能继续的情况 → 立即停止。
- 写操作造成线上可见内容（帖子/消息/订单）前，必须先取得驾驶员明确同意。
