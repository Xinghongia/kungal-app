# 2026-10-17 · BP-02 U2 词条详情与封面投票

## 本批做了什么

作品卡片不再跳网页，进入原生词条详情：

- 头部：封面/全部封面入口、标题、别名、资源轴、评分与评分人数、浏览/点赞/收藏数、
  点赞、收藏、评分、编辑资料、修订历史、DLsite 购买。
- 五个标签页：游戏介绍 / 本体资源下载 / 补丁资源下载 / 评论区 / 题库。
  本批交付「游戏介绍」的全部内容；资源/补丁（BP-03）、评论（U4）、题库（BP-05）为如实占位，
  每个占位都提供浏览器入口，不伪造空数据。
- 游戏介绍内：多语言简介切换（来源与机器翻译提示）、相关链接（VNDB/Bangumi/批评空间身份链接 +
  官网等目录链接）、作品信息（会社及职责、系列、引擎、原语言、发售日期、年龄限制、游玩时长聚合）、
  标签（内容/属性/成人分类 + 剧透档筛选，默认只显示无剧透）、制作人员（6 组折叠）、
  出演角色（图片、类型、剧透、声优）、画廊、系列（含样例作品）、关联作品、
  贡献者、外部评分（VNDB/Bangumi/批评空间/DLsite）。
- 收藏夹选择器：勾选/取消收藏夹、新建收藏夹（名称/描述/公开或私密），保存后回填心形与收藏数。
- 全部封面：按封面类型分组、显示票数、投票/撤票（一人一票，投另一张会移动）、
  按内容设置隐藏 explicit 封面、模糊模式打码、可看大图。
- NSFW：隐藏模式下词条先过门禁；模糊模式封面/截图/角色图打码并可点击揭示；
  角色 explicit 图在隐藏模式下不显示。
- 词条合并：服务端 409 `ENTITY_MERGED` 时自动跳到 `current_id`。
- 通知里的 `/galgame/{id}` 路径现在直接进原生词条（不再交给浏览器）。

## 核心接口

- `GalgameApi` 新增：`GET /works/{id}`、`PUT/DELETE /works/{id}/like`、
  `GET /me/cover-votes`、`PUT/DELETE /works/{id}/covers/{cover_id}/vote`、
  `GET /me/works`（批量读本人收藏夹归属/游玩记录，U4 复用）。

  `PUT/DELETE /collections/{id}/works/{id}`、`POST /collections`（幂等键，visibility 必填）。
- `Problem` 增加 `current_id` 扩展字段（合并跳转用）。
- 新增完整 `Work` 及 30 余个嵌套模型（封面/截图/会社/署名/角色/系列/关联/外部评分等）。
