# 2026-10-17 · BP-02 U1 资料库浏览

## 本批做了什么

把「Galgame」一级入口里的两个资料库从占位接到真实数据：

- **Galgame 资源资料库**（对应网页 `/galgame`）：只列本站已有下载资源的已发布作品。
- **Galgame 信息资料库**（对应网页 `/gallib`）：列资料库全部作品，含没有资源的条目。

两页共用同一套卡片与分页逻辑，差异只在请求接口、排序字段与筛选面。

## 接口与实现

- core 新增 `GalgameApi`：
  - `GET /works`（16 种排序 + 资源轴/年份/月份/收录/评分/提供商/标签排除筛选）
  - `GET /library-works`（热度/发售日期/资料更新排序 + 发售年份）
  - `GET /works/collected-months`（收录日历）
  - `GET /me/blocked-tags`（游标翻页；tree 放 `exclude_tag_trees`、exact 放 `exclude_tag_ids`）
- `WorkListQuery` / `LibraryWorkQuery` 集中构造查询参数；多值轴按重复键传递。
- app 新增 `ui/galgame/`：
  - `GalgameListViewModel`：页码分页（每页 24）、下拉刷新、触底加载、筛选变更重载、
    NSFW 姿态变化重载、标签屏蔽自动附加。
  - `GalgameListScreen`：两列封面卡片（5:7，NSFW 模糊/角标）、筛选条与底部选择面板、
    「更多筛选」、收录日历、发售年份、空态/错误态/加载态。
  - 筛选完整对齐网页：排序 + 升降序、平台（含「模拟器」转运行环境轴）、游戏类型、
    资源类型、语言、最低评分、评分人数、发售年份/月份、收录年份/月份、含/排除提供商、
    原始语言门槛（默认只显示日语/中文原语言作品）。
- AppNav：`/galgame` → 资源资料库，`/gallib` → 信息资料库。
- 标题取简体中文名优先，其次实体自带名；评分无人评分时不显示；发售日期缺失显示「发售日期未知」。
