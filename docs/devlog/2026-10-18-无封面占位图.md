# 2026-10-18 · 无封面 Galgame 显示站点占位图（0.7.7）

## 背景

驾驶员在发售月历对比网页时发现：网页对没有封面的作品显示官方「暂无封面」插图
（chibi 角色举着「封面不足」牌子），App 里只显示破图标占位，观感不一致。

## 实现

- 新增官方 web 公共资源 `apps/web/public/galgame-no-cover.webp`（256×455，AGPL-3.0，
  与已有的 `kun_loading` / `kun_empty` 插图同样只作界面装饰）到
  `app/src/main/res/drawable-nodpi/galgame_no_cover.webp`。
- `KungalImage` 增加可选的 `fallback` 参数：地址为空或图片加载失败时优先渲染业务占位，
  未提供时保持原来的破图标占位。
- 新增共享 `WorkCoverImage(url, isNsfw, blurNsfw, …)`：无封面/加载失败显示站点占位图，
  NSFW 且「模糊」时仍走打码封面；`NoCoverArtwork()` 按 contain 铺满、底色与网页一致。
- 接入位置：资料库两列卡片、实体作品行、排行榜作品行、资源列表与详情、词条详情头部、
  评分卡片与评分详情、用户主页作品/评分/资源/游玩时长列表、系列样例、关联作品、
  投稿候选卡片。搜索结果用的是同一套 `GalgameWorkCard`，自动生效。

## 证据

- `:core:test` 177 项、`:app:testDebugUnitTest` 89 项，合计 **266 项全绿**；
- `assembleDebug` 通过；版本 `0.7.6/code 27 → 0.7.7/code 28`，
  `USER_AGENT` 同步为 `kungal-app/0.7.7 (Android)`；
- APK 已装机，设备显示 `0.7.7`（code 28）；启动冒烟通过。

## 未验证与已知边界

- 占位图在月历、资料库、评分等页面的实际观感需驾驶员真机确认；
- 图片加载失败时也会回落到占位图（与网页 `Cover.vue` 的行为一致）；
- 网页占位图底色为 `bg-default-100`，App 用 `surfaceContainerHigh` 近似，深色主题下会随主题变化。
