# 2026-10-17 · 小布局修复（0.4.1）

## 本批做了什么

驾驶员实测反馈的三处小问题 + 一个类问题排查：

1. **话题评论里的「回复」二字改为黑色**
   - `ReplyUi.kt`：回复卡片底部操作行的「回复」显式用 `onSurface`；
     楼中楼评论里的「回复」按钮同样处理。
   - 不改变可点击反馈和禁用逻辑，只改文字颜色。

2. **资源资料库卡片平台标签在窄屏挤成竖排**
   - 根因：卡片里的 `Chip` 显示「Windows 电脑版 / 安卓手机版」这类全称，
     在两张半宽卡片里放不下，`Text` 自动换行把词拆成「安卓 / 手机 / 版」。
   - 修复：
     - `Chip`（共享组件）统一 `maxLines = 1, softWrap = false`——任何标签都不再折行；
     - 新增 `platformShortLabel(s)`：卡片/词条头部用短名（Windows、安卓、Switch、
       PS5 等），筛选项和详情资料仍保留全称。

3. **词条页「浏览量/点赞/收藏」上方的一大片空白**
   - 根因（用 `onSizeChanged` 实测确认）：头部右侧「类型 / 语言 / 平台」三组 chip
     塞在一个不换行的 `Row` 里。`Row` 把剩余宽度依次分给后面的子项，前两个 chip
     占满后，第三个 chip 只拿到近乎 0 的宽度，文字便逐字折行，把这一行撑到
     606px 高（正常应为 54px），于是它下方的浏览/点赞/收藏被推到很下面，
     中间留下大片空白。资源资料库卡片里「安卓手机版」竖排成三行也是同一个原因。
   - 修复：
     - 共享 `Chip` 改为单行（`maxLines = 1, softWrap = false, Ellipsis`），
       任何标签都不再逐字折行；
     - 词条头部三组 chip 收窄为「类型 1 + 语言 1 + 平台 2（短名）」并改用
       `FlowRow` 自动换行；详情操作行本身较长，改为可横向滚动。
     实测头部高度从约 1057px 降到 690px，空白消失。

4. **同类问题排查（宽度不够会向下挤）**
   - 编辑资料页头部操作行（返回词条 / 修订历史 / 我的提案 / 审核队列）→ 横向滚动；
   - 词条页点赞收藏评分行、编辑/历史/封面/DLsite 行 → 横向滚动；
   - 我的提交卡片操作行、提案卡片操作行、评分卡片与评分详情 chip 行 → `FlowRow`；
   - 不是统一改全局，只改了「一排胶囊/按钮」型布局；文字正文仍正常换行。

  - 资源资料库卡片平台是「Windows」「安卓」单行胶囊；
