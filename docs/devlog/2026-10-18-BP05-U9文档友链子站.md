# 2026-10-18 · BP-05 U9 文档、友链、子站与收尾（0.8.12）

## 背景

蓝图 U9：补齐帮助文档与友情链接的原生页面，子站页面按网页静态清单实现，
并把发现页/Galgame 页的最后一批占位入口清零。

## 改动

### core

- 新增 `DocApi`：`GET /docs`（游标分页、排序、分类、置顶筛选）与
  `GET /docs/{slug}` 详情；`Doc` 模型（摘要字段 + 可空正文树）。
- 新增 `FriendLinkApi`：`GET /friend-links`（游标分页、分类筛选）；
  `FriendLink` 模型（分类、标题、链接、简介、横幅、上下线状态）。
- 真实样本夹具：`docs.json`（29 篇）、`doc_detail.json`（版权政策，正文 10 个顶层块）、
  `friend_links.json`（43 条，3 条已下线），均为 2026-10-18 匿名实测；
  新增 `DocApiTest` 2 项、`FriendLinkApiTest` 2 项。

### app

- `/doc` 帮助文档列表：全量按 `position_asc` 拉取，分类筛选（Galgame / 网站公告 /
  关于鲲 / 其它）在本地；卡片显示横幅、分类、日期、标题与摘要；下拉刷新。
- `/doc/{slug}` 文档详情：
  - 横幅、标题、分类、浏览数、作者、发布/编辑日期与摘要；
  - 「文档目录」卡片取自正文顶层 heading，点按滚动到对应内容块；
  - 正文按顶层块逐项渲染，保留现有 Markdown/图片/表格渲染能力；
  - 右上角「文档索引」底部弹层按分类列出全部文档，可直接切换；
  - 底部「上一篇 / 下一篇」按网页同款 `published_desc` 顺序计算。
- `/friend-links` 友情链接：按官方网站 / Galgame 网站 / 其它网站分组，
  已下线站点带红色标记，卡片打开外链并带 `utm_source=www.kungal.com`；
  底部「加入我们」进 `/doc/contact` 原生文档。
- `/sites` 子网站：网页数据来自前端常量 `kunSubSites`（没有 API），
  App 内保持同一份静态清单（补丁站、账号中心、表情包、导航站、开发文档），
  卡片打开站点，GitHub 链接单独可点。
- 导航收尾：
  - 站内路径 `/doc`、`/doc/{slug}`、`/friend-links`、`/sites` 全部进原生；
  - 通知路径同样补齐；
  - 发现页「帮助与链接」与 Galgame 页入口全部替换占位，发现页/Galgame 页
    不再有 `soon` 占位入口。
- 新增 `DocUi`（分类文案、目录抽取、上下篇）与 `parseDocPath`（slug 校验）；
  app 单测覆盖目录抽取与路径解析。
