# BP-01 · 话题与讨论域全量

## 合同

把「能看话题」补成「能在 App 里完整参与讨论」：发帖、编辑、回复、楼中楼、反应、
投票、抽奖、收藏、订阅、推、隐藏、草稿、关注动态与话题搜索，全部走站点官方 v1 接口，
不绕过权限与萌萌点规则。

- 范围来源：`apps/web/app/pages/topic/`、`apps/web/app/components/topic/`、
  `apps/api/openapi/kungal-v1.json` 中 topics / replies / comments / polls / lotteries /
  reactions / subscriptions / drafts / following-activities / search 接口组。
- 不属于本蓝图：Galgame 资料库（BP-02）、工具集与资源（BP-03）、用户主页与私信（BP-04）、
  全站搜索中心与排行月历（BP-05）。话题内搜索先做「话题/回复/评论」三类结果页。
- 红线不变：不批量抓取；写操作带 `Idempotency-Key`；推话题消耗萌萌点必须显式确认；
  匿名/未登录时按站点规则返回 401，不做本地绕过。

## 交付批次与退出条件

### A. 编辑器与发帖闭环

- `TopicEditorScreen`：标题、Markdown 正文、分类、版块（1–3，随分类联动）、NSFW、
  访问范围（公开 / 登录可见 / 指定角色 / 指定用户）、封面（最多 9 张，来自已上传图片）。
- 图片上传：`POST /images`（multipart、`purpose=content`、`Idempotency-Key`，≤10MiB/张，
  每日 50 张由服务端限制），上传后把 `![图片](url)` 插入正文并可设为封面。
- 发布：`POST /topics`；成功后进入话题详情。
- 编辑：`GET /topics/{id}/source` → 预填 → `PATCH /topics/{id}`。
- 草稿：`POST/GET/DELETE /me/topic-drafts`，编辑器可随时存草稿、从草稿继续。
- 退出条件：登录账号在真机完成「写草稿 → 发布 → 编辑保存」；话题出现在列表且内容正确。

### B. 评论、反应与回复操作

- 详情页回复列表支持 `floor_asc` / `floor_desc`。
- 回复操作条：点赞/点踩与表情选择器（33 个 token）、反应历史、引用、编辑、删除、
  置顶/取消置顶、最佳答案（按 `viewer.can_*` 显示）。
- 楼中楼：回复下展示评论（含 `in_reply_to_user`），可发表评论、回复某条评论（`parent_comment_id`）、
  点赞、编辑、删除。
- 退出条件：真机完成一次「评论 → 回复评论 → 点赞 → 编辑 → 删除」；反应计数与网页一致。

### C. 收藏订阅、投票抽奖、动态与搜索

- 详情操作栏：收藏、订阅三档、推话题（确认消耗萌萌点）、隐藏/恢复、已读标记。
- 投票：展示选项与结果、单/多选投票、撤票、查看投票记录。
- 抽奖：详情、参与/退出、参与名单、中奖名单、兑换码揭示（按 `viewer` 权限）。
- 关注动态页：分组列表、未读数、进入后标记已读；入口放在「消息」页。
- 话题搜索页：话题/回复/评论三类结果，点结果进入话题；入口放在话题页顶栏。
- 退出条件：真机验证收藏、订阅、投票、抽奖各一次；关注动态与搜索能打开真实数据。

## 技术与证据要求

- core：所有新接口有离线单测（MockWebServer + 真实响应夹具，夹具脱敏、不含 cookie）。
- app：每批 `assembleDebug` 通过；每批结束装到驾驶员手机。
- 真机证据只覆盖新打通的写协议（发帖、评论、反应、投票、抽奖、收藏/订阅），
  其余页面由驾驶员自行走查。
- 站点契约以 `research/probe/2026-10-17/auth/` 的登录态样本与
  `research/probe/2026-10-17/topic_ops.txt` 为准；样本目录 gitignored。
- 失败如实报错：401 → 引导重登；403 `SCOPE_REQUIRED` → 提示重新授权；
  萌萌点不足/抽奖资格不满足等按 problem detail 显示，不重试轰炸。

## 停止条件

- 写操作在真机连续失败且无法区分是客户端还是站点限制；
- 站点对第三方客户端明确反制；
- 需要绕过登录、权限、积分或验证码才能继续。
