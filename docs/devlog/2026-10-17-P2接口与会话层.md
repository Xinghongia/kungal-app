## 完成内容

- **真实样本夹具**（`research/probe/2026-10-17/`，gitignored；脱敏副本进
  `core/src/test/resources/fixtures/`）：话题列表、话题详情、回复列表、401/404 problem+json。
- **KungalClient**：OkHttp；统一 base `https://www.kungal.com/api/v1`；
  - 会话：`SessionHolder` 注入 `Cookie: kungal_session=…`（匿名不带）
  - 错误：RFC 9457 problem+json → `KungalApiException`（`requiresLogin`/`isRateLimited`/
    `retryAfterSeconds`），解析失败按状态码兜底
  - 写通道：`postJson` 支持 `Idempotency-Key`（P3 点赞/回复用）
- **模型**（对齐官方 OpenAPI 与实测样本）：
  - `Topic`（一个模型吃列表子集与详情全量；`pinnedReply`/`bestAnswer` 直接复用 `Reply`）
  - `Reply`/`ReplyComment`/各 Viewer（has_liked/can_* 等权限位）
  - `ReactionSummary`（token + count + reactors + viewer）
  - `ContentDocument` 节点树：块节点与行内节点共 25 种全部建模；
    **未知 object 落 `UnknownNode` 不抛异常**（站点会加节点类型）；未知字段忽略
- **TopicApi**：`/topics`（cursor/limit/sort/category/section/include_nsfw）、
  `/topics/{id}`、`/topics/{id}/replies`（cursor/limit/sort/from_floor）。
