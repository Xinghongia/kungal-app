# 2026-10-17 · BP-02 U5 编辑提案与修订历史

## 本批做了什么

### 资料编辑工作台（`/galgame/{id}/edit` 的原生版）

- 动态读取 `GET /works/{id}/edit-form`，按网页的七个分组展示字段：
  标题 / 介绍 / 基本信息 / 关联条目 / 出演与署名 / 链接 / 图片；顶部标签栏切换分组。
- 已覆盖全部字段类型与站点当前字段：
  - 标题与别名：官方名（多语言）、别名/缩写、隐藏的上游标题键；
  - 介绍：按语言编辑多语言 Markdown（留空不提交该语言）；
  - 基本信息：条目名、原始语言、年龄分级、NSFW 素材开关；
  - 关联条目：系列 / 标签 / 会社（带身份）/ 引擎，搜索选择与移除；
  - 出演与署名：角色主配/剧透档、隐藏角色、本站署名（职务 + Staff 名义 + 配音角色 + 备注）、隐藏的上游署名键；
  - 链接：字符串列表；
  - 图片：封面上传/删除/上下移动/封面类型/竖版置顶/性内容与暴力分级；
    画廊上传/删除/上下移动/说明/分级；
  - 其他 schema 字段按 `text / i18nmap / enum / int / date / list / ref / imagehash` 通用控件兜底；
    未知的对象列表如实标为只读（当前站点没有这类作品字段）。
- 图片上传走 `POST /work-edit-images`（multipart：`file` + `preset=cover|screenshot`，≤10MiB），
  成功后用返回的 hash 写入提案，不保存 URL。
- 提交时只发送改动过的 `catalog.work.*` 键 + 说明；幂等键 UUID；
  立即合并提示「修改已生效」，否则提示「提案已提交，等待审核」。
- 工作台列出这部作品的待审提案：我的提案可撤回，可裁决的提案进入审阅页。
- 未登录进入编辑页时显示登录引导，不发编辑请求。

### 提案与审阅页

- 「我的资料编辑提案」（`/me/edit-proposals`）：全部状态、游标加载更多、撤回、刷新；
  入口在「我的」页与编辑页。
- 审核队列（`/edit-proposals`，需 `galgame.edit_proposal.review`）：
  待审核/已合并/已拒绝/已撤回四栏、游标加载更多；无权限时如实提示。
- 提案详情：
  - 提案人、状态、说明、基线版本、修正链；
  - 逐字段对比「当前值」与「提案值」；
  - 可裁决时支持「修正该值」（复用编辑控件）、「拒绝该字段」、「修正并合并」；
  - 合并/拒绝带 ETag 的 `If-Match`；拒绝必须填写说明；合并前先提交修正再读取新 ETag；
  - 只读查看已关闭的提案。
- 修订历史（`/galgame/{id}/history`）：
  - 修订时间线（版本号、来源、编辑者、最后修正人、时间、涉及字段）；
  - 任意两版本对比（字段级 from/to，复用编辑字段摘要），也支持「对比上一版」；
  - 回滚到指定版本（带可选说明、幂等键）；立即生成新修订或进入审核，按响应如实提示；
  - 从历史页可进入编辑页或查看对应提案。

### 接线

- 词条页「编辑资料」「修订历史」从打开浏览器改为原生页面；未登录点编辑先去登录。
- 站内链接分发支持 `/galgame/{id}/edit`、`/galgame/{id}/history`、
  `/galgame-edit/mine`、`/galgame-edit/review`、`/galgame-edit/review/{id}`。
- 「我的」页新增「我的资料编辑提案」入口。

## 核心接口

- `EditApi`：`edit-form`、`/works/{id}/edit-proposals`、`/me/edit-proposals`、
  `/edit-proposals`、提案详情、创建、修正、合并/拒绝/撤回、修订列表、diff、回滚、
  `POST /work-edit-images`。
- `MeApi.permissions()`：`GET /me/permissions`。
- `KungalClient` 新增保留响应头的 `getWithResponse / postJsonWithResponse /
  patchJsonWithResponse`（读取 ETag、Location）；`ApiResponse<T>`。
- 模型：`EditForm / EditField / EditVocabulary / EditProposal / EditProposalSummary /
  EditAmendment / EditRevision / EditRevisionDiff / EditRevert / PermissionList`；
  `WorkEditProposalCreateResult` 用自定义序列化器拆分内嵌提案与 revision。

## 已知边界

- 图片排序用上移/下移按钮，不做拖拽（网页是拖拽）。
- 通用控件无法编辑未知的“对象列表”字段（当前 schema 中的作品字段都有专用编辑器）；
  这类字段会显示只读摘要并提示去网页端修改。
- 提案列表接口本身不返回 patch，列表卡片只展示说明/状态；逐字段内容在详情页。
- 审核队列入口依赖 `/me/permissions`；Bearer 登录（官方 App 通道）永远为空，
  本项目走 cookie 会话，不受影响。
- 编辑表单的区域/多语言内容不会自动补全上游简介（网页会预填数据源简介）；
  原生端只显示/提交本站已有版本，避免误把上游文本写成本站版本。
