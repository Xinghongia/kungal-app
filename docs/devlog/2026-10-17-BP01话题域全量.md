# 2026-10-17 · BP-01 话题与讨论域全量

## 本批交付

把「只能看话题」补成「能在 App 里完整参与讨论」。范围与退出条件见
`蓝图集/BP-01-话题与讨论域.md`。

### core（接口层）

- `TopicApi` 扩到话题域全量：话题/回复/评论 CRUD、反应（话题与回复）、反应历史、
  收藏、订阅三档与已读、推话题、隐藏/恢复、批量状态、草稿、投票、抽奖、关注动态、搜索。
- 新增 `ImageApi`（`POST /images` multipart，`purpose=content`，幂等键）。
- `KungalClient` 增加 `putJson`/`patchJson`/`postMultipart`/`postNoBodyJson`/`deleteNoBody`。
- 模型：`TopicExtras`（草稿/订阅/状态/推/源文/请求体）、`Poll`、`Lottery`、`Activity`
  （关注动态、搜索命中、上传图片）。
- `KungalJson.encodeDefaults = true`：请求体里带默认值的必填字段（如 `access_scope`、
  `choice_type`）必须发出去。
- 15 项新单测（`TopicDomainTest`），夹具来自登录态真实响应（脱敏，`research/probe/` gitignored）。

### app（界面层）

- **发帖闭环**：`TopicEditorScreen`（标题 / Markdown 正文 / 分类 / 版块 1–3 / NSFW /
  访问范围公开·登录·角色·用户 / 图片上传与封面 / 存草稿 / 发布），
  `DraftsScreen`（草稿箱）。
- **编辑话题**：详情页 `viewer.can_edit` 时出现编辑入口，读取 `/topics/{id}/source` 预填；PATCH 保存。
- **回复增强**：正/倒序切换、引用回复、编辑、删除、置顶/取消、最佳答案；
  楼中楼评论展示与发表（含 `parent_comment_id`）、点赞、编辑、删除。
- **反应**：话题与回复共用反应条；33 个反应 token 的选择器（与站点 `constants/reaction.ts` 对齐，
  未知 token 用中性兜底）；反应历史弹窗；回复底部点赞/点踩。
- **互动**：收藏、三档通知订阅、推话题（确认弹窗说明消耗 10 萌萌点）、隐藏/恢复、已读标记。
- **投票**：单选/多选、投票/更新/撤销、结果进度条、匿名提示、投票记录。
- **抽奖**：奖品、参与/退出、参与名单、中奖名单、兑换码（按 `viewer.can_*` 显示）。
- **关注动态**（消息页入口，分组卡片 + 未读 + 打开即标记已读）；
  **话题搜索**（话题/回复/评论三 tab，入口在话题页顶栏）；**我的订阅**（我的页入口）。

### 驾驶员反馈修正

1. 详情页底部常驻回复框已删除；改为点击回复卡片上的「回复」或点击「回复某楼层」时，
   从底部弹出回复面板（与网站一致）。引用回复会带上楼层与 @ 用户。
2. 搜索框改为椭圆，搜索按钮与输入框同一行。
3. 修复回复「更多」菜单错位：菜单锚定在按钮所在 Box 内。
4. 回复菜单补齐：分享该回复、关注/取消关注 TA、举报（原因从 `/report-reasons` 加载，
   提交 `forum_reply` 举报）。
5. 反应面板对齐网站：点赞/点踩带说明，31 个表情网格，底部显示回应人数与「查看历史」；
   点击立即发送反应，再点一次取消；已选中的项有强调色 + 对勾。
6. 反应图标改用站点动态 WebP（`https://www.kungal.com/emoji/<token>.webp`），
   通过 Coil `coil-gif` 动图解码器播放，与网站一致。
7. 回复/评论发布时间精确到秒：`yyyy-MM-dd HH:mm:ss`（话题发布时间也一样）。
8. 已点赞/已回应的 chip 与未回应有明确区分：填充强调色 + 描边 + 对勾 + 加粗计数。
9. 正文图片点击打开全屏查看器：双指缩放/拖动、保存到相册、复制链接、分享。
