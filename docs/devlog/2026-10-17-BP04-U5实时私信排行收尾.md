### core（接口层）

- `ChatApi` 新增（U5 部分）：
  - `POST /chat/realtime-token` → `ChatRealtimeToken {token, expires_at, url}`；
  - `GET /chat/updates?after=&limit=` → 增量页（updates / messages / conversations / users /
    last_update_seq / has_more / too_long）；
  - `POST /chat/conversations/{id}/typing`（输入中，服务端按会话 5 秒节流）；
  - `GET /chat/reactions`（33 种表情回应）；
  - `PUT /chat/messages/{id}/reaction {reaction}`（`reaction=null` 取消；**显式发 null**，
    不受 `explicitNulls=false` 影响）；
  - `PUT/DELETE /chat/conversations/{id}/pins/{seq}`（消息置顶/取消）。
- 新增 `chat/ChatRealtimeClient`：Centrifugo JSON 协议最小客户端（OkHttp WebSocket）。
  - 连接命令 + JWT、connect 回复、服务端空帧心跳回空帧、`push.pub.data` 解析；
  - 一帧多行 JSON 与整帧 JSON 都能解析；服务端要求断开（`push.disconnect`）时结束连接；
  - 提供 `pushes: SharedFlow<ChatPush>` 与 `awaitDisconnected()`，重连与补齐由上层负责。
- 新增 `RankingApi`（`/rankings/users|topics|works`，`sort`/`limit`/`include_nsfw` 等）；
  `model/Ranking.kt` 三个榜单条目（复用 `UserRef` / `Topic` / `WorkRef`）。
- `MeApi` 新增 `preferences()` / `savePreferences(doc, version)`：云端偏好文档按 `JsonObject`
  原样读写，写回带 `If-Match: "<version>"`；`KungalClient.putJson` 支持自定义请求头。
- 单测新增 8 项：实时凭证/补齐、回应列表与设置取消、输入中/置顶、排行榜三张表、
  云端偏好 If-Match、Centrifugo 握手+推送+心跳（MockWebServer WebSocket）。

### app（界面层）

- **实时通道（App 级 `ChatRealtimeHub`）**
  - 登录后连接、登出断开；token 约 15 分钟有效，到期前主动换新连接；
  - 先订阅推送再按 `/chat/updates` 补齐，断线重连后从上次 `last_update_seq` 继续；
  - 推送序号出现空洞时等待 500ms 再整段补齐；
  - 新消息推送同时刷新消息 tab 角标。
- **会话列表**：收到推送自动静默刷新当前文件夹与未读数；「对方正在输入…」预览；
  顶部在实时通道未连接时明确提示「可手动刷新」。
- **会话页**：
  - 实时接收新消息/编辑/删除/已读/回应/置顶/会话状态变化，无需手动刷新；
  - 输入中提示（顶部与输入框上方），输入文字时限频上报；自己最后一条消息显示「已读」；
  - 表情回应：长按菜单快捷回应 8 个 + 完整 33 种选择面板，气泡下显示计数 chips，再点取消；
  - 消息置顶：会话菜单 → 置顶消息列表（点击跳转、取消置顶）；顶部置顶条；跳转后可「回到最新消息」；
  - 会话置顶/取消置顶、静音/取消静音加入会话菜单；
  - 实时通道不可用时保留手动刷新按钮与「未连接」提示。
- **排行榜**：用户（萌萌点/话题/回复/评论/资源）、话题（浏览/回复/评论/点赞/被推/收藏）、
  Galgame（浏览/点赞/收藏/资源/评分）三栏 + 排序；前三名奖牌样式；用户/话题进 App，

- **云端偏好**：设置 → 账号 → 云端偏好；读取/写回 `/me/preferences` 的 14 项

## 驾驶员反馈修正（同批）

1. **正文与评论不能长按选字**：`ContentDocumentView` 外层包 `SelectionContainer`，
   文章、回复、楼中楼评论里的文字都能长按选择、复制；链接与剧透点击行为不变。
2. **系统 Toast 太丑**：新增 `AppMessages` / `AppMessageHost`，挂在导航根部 Scaffold 的
   snackbarHost 槽位，用当前主题的 Material 3 圆角提示取代全部 `Toast.makeText`
   （复制、分享、无浏览器、清图片缓存）。图片查看器是独立 Dialog 窗口，根部提示被遮挡，
   改为查看器内部的主题化提示条（保存结果/复制/分享失败）。
   第二轮：页面内的 `SnackbarHost` 同样是 Material 默认深色横条（收藏、订阅、购买、
   通知删除等提示都走它），统一换成 `KungalSnackbarHost`（圆角 + `surfaceContainerHighest`
   + 主题文字色，左右留 16dp），覆盖全部 14 个使用中的页面。
3. **资料设置隐私开关卡顿**：原因是点击后立即把开关设为 `enabled=false`（变灰）且等待网络返回。
   改为点击立即切换、保持可点，300ms 防抖后只提交最后一次状态；失败回滚并提示。
   开关整行可点，动画与设置页一致。
4. **长按选中的文字点空白不取消**：话题详情页给列表加空白区域点击手势，
   通过 `LocalTextSelectionClearSignal` 通知每个 `ContentDocumentView`
   （`SelectionState.clear()`）清空选择；正文与评论、回复都生效。
   真机验证（15:27）：长按正文出「复制/全选」菜单，点击右侧空白后选中高亮与菜单同时消失。
5. **评论/回复头像全是灰色占位图**：站点约 94% 的账号没有上传头像，网页用
   KunUI `pickAvatarFallback`（`h*31+charCode` 取模）从 64 张默认头像池里按用户名挑图。
   App 复刻同一算法与同一份图片池（`AvatarPool`，内置快照 + 启动时刷新
   `sticker.kungal.com/api/v1/avatar-pool`），所有头像位置按用户名传入 seed。
   用线上网页 HTML 反查校验：`战神金刚` 命中池内第 47 张，与网页实际渲染一致。
   新增 `AvatarPoolTest` 3 项（含真实用户样本）。
