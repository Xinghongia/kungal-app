# 2026-10-18 · 关于页：免责说明、隐私协议、关于我（0.8.14）

## 背景

驾驶员要求在「我的 → 关于」增加三个页面：免责说明、隐私协议、关于我。
关于我展示个人介绍、5 个 GitHub 项目与贡献热力图。

## 改动

### core

- 新增 `GitHubPublicApi`：读取 GitHub 公开网页
  - `contributions(user)`：解析 `github.com/users/{user}/contributions` 的
    `data-date/data-level` 单元格与「N contributions in the last year」，按周日开头的
    周网格组织（最后一周未来日期为 null）
  - `repoStars(owner, repo)`：解析仓库页里的 `"stargazerCount":N`；仓库不可见（404）返回 null
- 新增模型 `GitHubContributionDay`、`GitHubContributions`
- 夹具：贡献页与仓库页各一份裁剪样本；`GitHubPublicApiTest` 3 项
  （总数与周排布、star 解析、404 返回空）

### app

- 新增「关于我」页：头像、简介、GitHub/博客入口、5 个项目卡片（语言、star、
  Fork/即将开源标记）、GitHub 贡献热力图（近一年总数、5 级配色、水平滚动、图例）
- 新增「免责说明」「隐私协议」两个静态页面，内容按应用实际行为编写
  （本地保存项、访问的域名、不收集的数据、用户控制方式）
- 新增 `GitHubProfileStore`：贡献与 star 本地缓存 24 小时，避免重复请求
- 「我的 → 关于」新增三个入口；新增路由 `about/me`、`about/disclaimer`、`about/privacy`
- 单测：`GitHubProfileStoreTest` 3 项（缓存时效）

## 为什么读网页而不是 GitHub API

匿名 GitHub REST API 额度是**每 IP 每小时 60 次**，不是「每设备」；移动网络多为共享出口。
实测 2026-10-18 本机出口的匿名额度已是 0/60（被同一出口的其他请求用光），
API 方案会经常拿不到 star。改为读取公开网页：每次打开关于页最多 6 个请求
（1 个贡献页 + 5 个仓库页），24 小时内不重复，失败时显示缓存或降级提示。

## 隐私说明

- 只读取公开数据：公开贡献、公开仓库 star、GitHub 公开头像；不携带任何 token；
- 未登录视角的贡献图**只含公开贡献**（实测同一账号匿名 262 次 vs 登录 405 次）；
- `kungal-app` 仓库目前为 private，匿名请求仓库页得到 404，卡片显示「即将开源」且不显示 star；
- 请求域名（github.com、avatars.githubusercontent.com）已写进应用内隐私协议。
