# 2026-10-17 · BP-03 U3 资源详情与我的资源（0.5.2）

## 本批做了什么

### 资源详情页（`/galgame/resource/{id}` → 原生）

- 作品卡：封面（NSFW 按内容姿态模糊）、作品名、NSFW/SFW 标识、
  「浏览更多资源」「查看这个 Galgame 的更多资源」两个出口。
- 资源面板：
  - 标题（作品名 + 平台 + 语言 + 类型 + 资源下载）、类型/语言/平台/运行环境/体积/下载/浏览；
  - 作者与发布时间、有效/失效标识；
  - 下载备注按站点文档树渲染（Markdown 内容）；
  - 「获取链接」领取后列出下载链接（点击由系统浏览器/网盘 App 打开）、
    逐条复制、提取码/解压码一键复制、DLsite 正版入口；
  - 编辑/删除/报告链接过期/重新标记有效（按权限与状态显示）；
  - 「反馈资源问题」跳到作品页。
- 同作品推荐：最多 6 条其它资源，点击进对应详情。
- 资源评论墙：`subject_type=galgame_resource`，maxLength 5000，复用现有评论组件。
- 详情 404：
  - 查询 `/galgame-resource-relocations/{id}`；
  - 有迁移记录 → 显示「已迁移到 LetMoe」卡片与前往按钮；
  - 没有 → 如实显示「未找到或已被移除」。

### 我的资源管理

- 用户主页「资源」标签页：
  - 本人「发布」列表出现「标记为有效」（失效资源）与
    「更改链接 / 更改链接并标记为有效」（过期筛选下）；带确认弹窗；
  - 更改链接复用发布/编辑弹窗，先读 `/source`，只提交变化字段；
  - 在「过期」筛选下保存后按网页行为自动标记有效并刷新；
  - 「点赞」列表不再传 `state`（与网页一致，点赞过的失效资源也能看到）。
- 资源条目点击改为进原生详情页，不再跳网页。
- 词条页资源区新增「批量更改已失效资源链接」入口（登录后显示），
  直达本人「资源 → 过期」列表（`/user/{id}?tab=resource-expire` 站内路由）。
- 资源详情也接入通知路径分发（`/galgame/resource/{id}`）。

### core

- `UserApi.resources` 的 `state` 改为可空：传 null 时不发送该参数（点赞列表用）。
- 新增 1 项单测验证点赞列表不带 state。
