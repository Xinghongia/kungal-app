# 2026-10-18 · BP-05 U6 情报投稿（0.8.8）

## 背景

BP-05 下一批 = U6：把网页的情报投稿（`/edit/news`、`/edit/news/{id}`、`/news/mine`）
补成原生功能。这是 BP-05 里唯一一批写操作：新建投稿、编辑、撤回、封面上传，
全部需要登录，真实验证留待驾驶员本人操作。

## 契约与样本

- OpenAPI：
  - `GET /me/news-submissions`（游标 + limit，默认 20）
  - `GET /me/news-submissions/{id}`、`POST /me/news-submissions`（Idempotency-Key 必填）、
    `PATCH /me/news-submissions/{id}`
  - `POST /me/news-submission-images`（multipart `file`，JPEG/PNG/WebP，≤4,000,000 字节，
    Idempotency-Key 必填，返回 Image 记录）
- 网页行为：标题/导语各 ≤200 字；正文 ≤20000；原文链接 ≤1024 且必须 http(s)；
  正文与原文链接至少一项；封面上传 16:9、1280 宽、提交时才上传（省每日额度）；
  pending/published 可编辑，published 保存后重新进入审核；撤回仅 published，
  撤回后是终态；状态文案 待审核/已发布/未通过/已撤回。
- 上述端点需登录，匿名实测 401，因此响应夹具按官方 schema 与网页用法手工构造
  （`news_my_submissions.json`、`news_submission_detail.json`、`news_banner_upload.json`）。

## 改动

### core

- `NewsSubmission`、`NewsSubmissionCreate`、`NewsSubmissionPatch` 模型
  （null 字段不序列化，patch 只发变化项）。
- `NewsSubmissionApi`：我的投稿 / 单条 / 创建（幂等键）/ 更新 / 撤回（state=withdrawn）/
  封面上传（multipart + 幂等键）。
- `NewsSubmissionApiTest` 6 项：游标参数、详情、创建幂等键与空字段省略、
  patch 只发变化字段与移除封面空串、撤回只发 state、multipart 上传。

### app

- `NewsSubmissionUi.kt`（纯函数）：与网页 zod 一致的校验、新建请求体、
  编辑差异请求体、可编辑状态与状态文案。
- `NewsBanner.kt`：相册图片按 EXIF 摆正、居中裁成 16:9、缩到 1280×720、
  JPEG 压缩至 ≤4 MB；解码失败时退回原图并检查大小。
- `NewsEditorViewModel.kt`：加载原稿；提交时先按需上传封面再新建/更新；
  创建幂等键在成功后轮换；published 保存提示「重新进入审核」。
- `NewsSubmissionScreens.kt`：
  - `/news/mine` 我的投稿：状态胶囊、封面/导语、时间；编辑与撤回（二次确认）；
    游标「加载更多」；从表单返回自动刷新。
  - `/edit/news` 与 `/edit/news/{id}`：标题、导语（字数）、16:9 封面选择/预览/移除、
    Markdown 正文、原文链接；published 重新审核提示；未通过/已撤回不可编辑。
- 接线：情报总览右上「投稿」与「我的投稿」入口；发布页「发布 Gal 情报」；
  我的页「我的情报投稿」；站内路径 `/news/mine`、`/edit/news`、`/edit/news/{id}`
  进原生（未登录先去登录）。
