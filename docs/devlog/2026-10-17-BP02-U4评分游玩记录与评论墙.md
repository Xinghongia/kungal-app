# 2026-10-17 · BP-02 U4 评分、游玩记录与评论墙

## 本批做了什么

### 评分

- 「Galgame 评分」列表：最新/最早、浏览最多/最少、评分最高/最低六种排序，
  剧透程度、游玩状态、游戏类型筛选，分页；剧透评分在列表里只显示提示，点进详情才展开。
- 评分详情：作品卡（可进词条）、作者（可进主页）、总分/推荐度/游玩状态/游戏类型/
  剧透档、短评（剧透门禁）、八维评分条、浏览/点赞/评论数、最近点赞者、点赞、
  作者可编辑（复用评分表单）与删除。
- 词条页「评分」按钮打开原生评分表单。

### 评分 / 游玩记录表单

- 游玩状态（想玩/在玩/完成一条线/完成主线/全通/搁置/弃坑）、总体评分 1–10、
  推荐程度、剧透程度、游戏类型（多选，附说明）、短评（≤2000 字）、
  可选八维高级评分、游玩时长（小时）。
- 与网页一致的规则：想玩状态不能评分；保存会整体替换记录，未发送的评分/时长会被删除
  （有删除评分/撤回时长的二次确认）；不足 10 分钟不计入统计；评分奖励萌萌点提示。
- 词条页保存后会刷新词条的评分与浏览数据。

### 评论墙

- 词条「评论区」与评分详情「评分评论」都接了原生评论墙：
  发布、回复（两层展示，按根评论分组）、点赞、编辑（读取源文）、删除（墓碑）、举报；
  审核中的评论显示「审核中」标记；管理员编辑与已编辑标记；游标分页加载更多。
- 未登录时显示「登录后参与评论」入口；字数上限与网页一致（词条 5000、评分 1314）。
- 评论正文使用服务端 ContentDocument + 既有统一渲染器（图片可点开大图）。

## 核心接口

- `RatingApi`：评分列表（筛选/排序）、详情、创建、修改、删除、点赞/取消。
- `WallCommentApi`：评论列表（游标）、发布、编辑、删除、点赞/取消、举报、读取源文。
- `GalgameApi` 新增 `GET/PUT /works/{id}/record` 与 `PUT/DELETE /works/{id}/playtime`。
- 新增评分/记录/评论墙模型 20 余个；`RatingSummary` 补齐 viewer。

## 已知边界

- 评论表单是纯文本 Markdown 输入（无网页的富文本工具栏/表情面板）。
- 评论区的「关注此墙」开关未做（关注墙列表在 BP-04 已有；从评论墙关注的入口后续补）。
- 评分本身的上报入口（举报评分）未做；评分下的评论可举报。
- 评分编辑复用「评分与游玩记录」表单，因此会同时读取/提交游玩状态与时长（与网页一致）。
