# 2026-10-18 · BP-05 U7 网站资料库（0.8.9）

## 背景

BP-05 下一批 = U7：把 Galgame 页里「Gal 网站资料库」占位替换成原生页面，
对齐网页 `/website`、`/website/{host}`、`/website-category/{slug}`、`/website-tag/{slug}`。

## 契约与样本

- OpenAPI：`/websites`（游标、include_total、include_nsfw、分类/标签筛选）、
  `/websites/{host}`（每次读取使访问量 +1，网页同样）、`/website-categories`、
  `/website-categories/{slug}`、`/website-tags`、`/website-tags/{slug}`、
  `/website-tag-groups`、`PUT/DELETE /websites/{host}/like`、
  `PUT/DELETE /websites/{host}/favorite`。管理面（/admin 下接口）按蓝图不做。
- 评论墙：`/wall-comments` 的 `subject_type` 封闭词表包含 `website`，
  网页评论上限 1007 字；关注开关不做（现状与其他评论墙一致）。
- 2026-10-18 匿名实测 8 个请求全部 200：SFW 站点 69 个（含 4 个已关站）、
  打开 NSFW 后 88 个；分类 4 个、标签 73 个、标签分组 18 个；详情样本
  `www.letmoe.com`（19 个标签，访问量 8723）。样本存
  `research/probe/2026-10-18/website/`（gitignored）。
- 网页行为：一次性拉全量后在本地按分类分组、组内按分数降序（同分按 id 降序），
  已关站单独存档区；搜索匹配标题/描述/域名；标签价值之和 = 网站分数，
  「价值精算值」上限按单选组取最高档、多选与未分组累加正分。

## 改动

### core

- `WebsiteEntry / WebsiteDetail / WebsiteCategoryRef / WebsiteCategory /
  WebsiteTag / WebsiteTagGroup / WebsiteViewer / WebsiteEngagement / WebsiteFeedPage` 模型。
- `WebsiteApi`：列表 / 详情 / 分类列表与单条 / 标签列表与单条 / 标签分组 /
  点赞与收藏（PUT 添加、DELETE 取消，返回最新计数与本人状态）。
- 真实样本夹具 7 份，`WebsiteApiTest` 5 项（列表参数与解析、详情、分类标签分组、
  点赞/取消、收藏/取消）。

### app

- `WebsiteUi.kt`（纯函数）：语言与状态文案、访问链接（补协议 + utm_source）、
  分数排序、搜索匹配、分类分组与已关站分区、标签颜色分档、分数配色、
  理论最高分、按标签分组聚合、价值条分段。
- `/website` 总览：搜索、默认只显示 SFW 提示、按分类分组卡片、
  已关站存档区（灰显图标与状态角标）、NSFW 角标、总数。
- `/website/{host}` 详情：图标/标题/访问量与更新时间/状态与语言、
  简介、标签胶囊（点击进标签页）、网站价值精算值（总分、分组占比条、
  图例、可展开的分组与标签价值明细）、点赞/收藏（乐观保护 + 服务端校准）、
  访问网站（浏览器 + utm）、网站信息（分类/状态/语言/年龄限制/域名列表复制）、
  统计信息、评论墙。
- `/website-category/{slug}` 与 `/website-tag/{slug}`：实体信息 + 该分类/标签下
  全部网站，按价值降序。
- 接线：Galgame 页「Gal 网站资料库」入口从占位换成原生；站内路径 `/website`、
  `/website/{host}`、`/website-category/{slug}`、`/website-tag/{slug}`；
  通知路径 `/website/{host}` 进原生详情。
