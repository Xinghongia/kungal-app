# BP-03 · 资源与工具集域

## 合同

把资源相关的三块能力补成网站同款：

1. **Galgame 下载资源**：全站资源列表（`/galgame/resource`）、词条页「本体资源下载」标签页、
   资源详情页、发布/编辑/删除、点赞、下载链接领取、失效报告与重新标记有效、我的资源管理。
2. **补丁资源**：词条页「补丁资源下载」标签页，数据来自 moyu（只读，跳转网页下载）。
3. **工具集**：列表（筛选/排序/搜索）、详情（介绍、实用性评分分布、收藏、评论、资源下载）、
   创建/编辑/删除、工具资源发布（外链或 S3 托管文件上传）、资源编辑/删除。

全部走站点官方接口；下载用系统打开 + 复制链接（驾驶员 2026-10-17 确认）；
写操作复刻官方请求并带 `Idempotency-Key`，不绕过权限、不批量抓取。

- 范围来源：OpenAPI `galgame-resources / galgame-resource-relocations / toolsets / toolsets uploads /
  works resources / works moyu-patches / users galgame-resources / users toolsets`；
  web 页面 `pages/galgame/resource/*`、`pages/toolset/*`、`pages/edit/toolset/*`、
  `components/galgame/resource/*`、`components/galgame/patch/*`、`components/toolset/*`。
- 不属于本蓝图：站内搜索/月历/题库/情报（BP-05）；补丁实际的下载在 moyu，不在本 App 下载。
- 红线不变：不批量抓取；写操作带幂等键；删除类会扣 3 萌萌点，必须二次确认；
  不冒用官方身份；官方源码只读，不复制代码（分享文本识别等行为自己实现）。

## 已核实事实（2026-10-17 OpenAPI + 匿名只读探测）

- `GET /galgame-resources` 匿名 200：页码分页（`page/limit`，网页 50/页），`q` 搜索，
  `include_nsfw` 跟随内容姿态；`total` 可能封顶 10000（`total_relation=gte`）。
- `GET /works/{work_id}/resources` 匿名 200：词条下资源；网页一次拉全（100/页）后按网盘分组，
  组内随机、失效排最后，多于一组时显示网盘标签。
- `GET /galgame-resources/{id}` 匿名 200：含 `work`（WorkRef + 封面）、`author`、`content`
  Markdown 文档、`dlsite`、`provider_names`、`viewer`（登录时含 `has_liked/can_edit/can_delete`）。
- `POST /galgame-resources/{id}/downloads` 发放链接（下载数 +1）；
  `POST .../expiry-reports` 服务端先核验，`verdict=alive|dead|unchecked`；
  `PATCH ... {state:"valid"}` 仅用于重新标记有效。
- `GET /works/{work_id}/moyu-patches` 匿名 200：游标分页；只有 `web_url`，没有下载链接；
  网页只在有补丁资源时显示该 tab。
- `GET /toolsets` 匿名 200：页码分页（网页 24/页），筛选 `toolset_type/interface_language/platform/
  release_channel`，排序 `resource_updated|created|view` × `desc|asc`，`q` 搜索。
- `GET /toolsets/{id}` 匿名 200：**每次读取 view_count +1**；含 `toolset_resources`、`contributors`、
  `practicality_distribution[5]`、`viewer`（`can_edit/can_delete/practicality_rating/has_favorited`）。
- 工具资源：`file`（S3 托管）与 `link`（外链）。下载 `POST .../downloads`：file 返回预签名 URL +
  `expires_at`，link 返回原链接。
- 上传：≤50MB 单次 PUT；>50MB 5MB 分片 PUT + ETag，再 PATCH 完成；仅 .7z/.zip/.rar，最大 2GB；
  每日额度 = 100MB + 萌萌点×1MB（当日已用 = `/me` 的 `toolset_upload_today_bytes`）；
  单文件上限 = min(max(100MB, 萌萌点/10 MB), 2GB)；上传会话可查询续传/中止。
- `POST /toolsets`、`POST .../resources`、`POST .../uploads` 均需 `Idempotency-Key`；
  创建类返回 201（资源发布带 Location/ETag）。
- 用户资源/工具集列表匿名 200（`GET /users/{id}/...`），现有 App 已有只读摘要 tab。
- 现有 App 接入点：词条页 RESOURCE/PATCH 占位；发现页与发布页占位入口；通知路径已映射；
  `Me.toolsetUploadTodayBytes` 与墙关注接口已在 core。

## 失败回退

- 资源详情 404 → 查 relocation；有结果给「资源已迁移到 LetMoe」出口，否则如实显示未找到。
- 失效报告 `alive` → 提示链接仍有效；`unchecked` → 按失效处理并刷新；网络错误给重试。
- 工具集详情读取会使浏览数 +1 → 不做无意义重复刷新。
- 上传中断 → 保留续传记录，重新进入可续传；服务端拒绝 → 如实提示，不循环重试。
- 下载链接过期（file）→ 重新点击获取新链接；magnet/ed2k/thunder 交给系统处理，失败给复制入口。

## 停止条件

- 站点关闭匿名资源读取或要求登录 → 带证据回驾驶员门。
- 上传接口或配额规则变化（字段/限制与服务端不符）→ 重新抓样本、更新夹具，完成后再继续。
- 需要绕过权限、批量抓取或冒用身份才能继续 → 立即停止。
- 扣分/删除类写操作造成线上可见变化前，必须先取得驾驶员明确同意。
