# 2026-10-17 · BP-05 U1 全站搜索（0.7.0）

## 背景

BP-05 全站搜索：原 App 只有话题/回复/评论三类搜索，网页搜索页有十类结果
（全部 / Galgame / 话题 / 资料库 / 资源 / 用户 / 回复 / 评论 / 游戏评论 / Gal 工具）、
搜索历史、关键词高亮与作品高级筛选。

## 接口（2026-10-17 OpenAPI + 匿名探测，样本在 `research/probe/2026-10-17/bp05/`）

- `GET /search/users`：`q/page/limit`，页码分页，`total_relation=gte` 时表示「至少 N」。
- `GET /search/wall-comments`：`q` 至少 2 字，游标 + limit，无 total；结果带
  `subject_type / subject_path`，可直接交给站内路径分发。
- `GET /search/works`：`q/page/limit/sort` + `company_id / tag_ids / released_from /
  released_to / include_nsfw / exclude_tag_ids / exclude_tag_trees`；
  `sort` 取值 `relevance_desc`（相关度）/ `popularity_desc`（热度）/ `released_desc` /
  `released_asc` / `updated_desc`。
- `GET /search/topics|replies|comments` 返回统一分页信封（含 `total`）；
  原 `TopicApi` 只按游标列表解析，本次一并改为 `PagedList`，搜索页才能显示总数与翻页。

## 实现

- core：新增 `SearchApi`（用户 / 作品 / 留言墙）与 `UserSearchHit`、`WallCommentSearchHit`
  模型；3 项新单测（用户/留言墙/作品筛选参数与解析）。
- app：搜索页重做为全站搜索：
  - 十个 tab，数量来自「全部」并行预览（话题 8 / 作品 12 / 资料库每类 8 / 资源 6 /
    用户 8 / 回复与评论与工具各 4 / 留言墙 4）；单 tab 24/页加载更多；
  - 搜索历史（DataStore，去重后置、最多 20、可单删/清空）；
  - 关键词按空白拆词、忽略大小写高亮标题/摘要/昵称/简介；
  - 作品筛选：排序、会社（可搜索单选）、标签（可搜索多选，最多 10）、发售年份区间；
  - 资料库子类：全部 / 角色 / 会社 / Staff / 标签 / 系列 / 引擎；
  - 结果跳转全部走原生页面：话题、用户、作品、资源、工具集、六类实体；
    留言墙按 `subject_path` 分发（尚未原生的网站/题库先开浏览器）。
- 内容姿态：登录跟随账号、未登录跟随本机设置，NSFW 参数与封面打码沿用全局逻辑；
  标签屏蔽从 `/me/blocked-tags` 读取并传给作品搜索。
- 发现页/Galgame 页原有搜索入口不变；新增 `/search` 站内路径分发。
