# 2026-10-17 · 全站页码分页器（0.7.2）

## 背景

驾驶员发现所有列表都只有「加载更多」，没有网站底部的页码分页器
（`‹ 1 2 3 4 … 406 ›`、跳转到指定页）。核对网页后确认：

- 网页的**页码式**接口（资源列表、资料库、目录实体、评分、工具集、搜索结果、用户内容标签等）
  使用 `KunPagination`；
- 网页的**游标式**接口（话题流、通知、私信、关注动态、新闻流、活动时间线等）使用
  「加载更多」/触底加载，不显示页码。客户端按同样口径处理，游标列表保持原样。

## 实现

### 共享分页器

- 新增 `ui/components/PaginationBar.kt`：`‹` `›` 翻页、首尾固定 + 当前页前后各两页、
  省略号、当前页主题色圆形高亮；「跳转」打开页码输入弹窗（1–总页数校验）；
  总页数 ≤1 时自动隐藏。
- `pageCount(total, pageSize)` 辅助函数；页码序列 `pageTokens` 可单测。

### 通用列表

- `PagedListContent` 增加 `pagination` / `pageSize` 参数与 `PageResult.total`：
  - `pagination = true`：底部显示分页器，翻页替换当前页并回到顶部，不再触底加载；
  - 默认 `false`：游标接口维持触底加载 / 加载更多。
- 所有页码式列表已切到分页器：
  - 资源资料库、信息资料库（两列网格）；
  - Galgame 资源列表（50/页）、工具集列表（24/页）、评分列表（24/页）；
  - 全站搜索的 Galgame / 话题 / 用户 / 回复 / 评论 / 资源 / 工具 / 资料库各 tab
    （「游戏评论」为游标接口，保留加载更多）；
  - 目录实体列表（标签/会社/引擎/系列/角色/特质）与实体作品列表、特质角色列表
    （24/页，特质 50/页）；
  - 收藏夹详情、我的收藏夹；
  - 用户主页全部页码式标签：话题/回复/评论（50/页）、作品/评分/收藏夹/工具集（24/页）、
    资源与题库（50/页）；游玩记录为游标接口，保持加载更多。
- 未改：话题流、通知、关注动态、私信、搜索历史、词条/工具集详情内的游标列表
  （网页同样没有页码）。

## 未验证与已知边界

- 分页器观感、窄屏页码换行/滚动、跳转弹窗与翻页手感需驾驶员真机确认；
- 题库、情报等尚未实现的域在对应批次里直接使用同一分页器；
- 页码式列表的「下一页」不会沿用滚动位置（每次回顶部），与网页一致；
- 总数为 `gte`（如 10000+）时按 10000 计算页数，与网页上限一致。
