# 2026-10-17 · BP-03 U2 词条资源标签页与补丁（0.5.1）

## 本批做了什么

### 词条页「本体资源下载」标签页

- 拉取词条全部资源（100/页，最多 10 页），按网盘分组：
  百度 / 夸克 / 移动云盘 / 123 / 迅雷 / 蓝奏 / 其他；组内失效排最后，
  其余按资源 id 稳定排序（网页为随机序，这里保证同一页面刷新顺序稳定）。
- 资源卡片：
  - 作者头像/昵称/发布时间、有效/失效标识；
  - 类型、标题、体积、平台、语言、运行环境、版本标签；
  - 备注纯文本（超过 3 行可展开）；
  - 网盘名、下载数、点赞（本人资源不显示点赞）；
  - 「获取资源」下载弹窗；本人/有权限时显示编辑、删除、重新标记有效；
  - 非本人且未失效时显示「报告失效」；
  - 报告失效后按网页展示两行状态（检测中/仍有效/已失效/无法核验/失败）。
- 下载弹窗：有效/失效横幅、作者与时间、网盘、备注、下载链接（点击交给系统，
  长链接可复制）、提取码/解压码一键复制、DLsite 正版入口、评分引导。
- 发布/编辑弹窗：
  - 链接（支持直接粘贴分享文本，一键识别链接/提取码/解压码，多链接逗号分隔）；
  - 标题、体积（数字 + MB/GB）、提取码、解压码；
  - 类型、适配版本、语言、平台、运行环境（有运行环境轴的类型必填）；
  - Markdown 备注；
  - 编辑时先读 `/source`，只 PATCH 变化的字段；清空版本标签发送显式 null；
  - 前端校验与站点一致（1–20 条链接、体积格式、语言/平台/运行环境必填、长度上限）。
- 作品禁止发布资源 / 资源在 LetMoe 的提示与入口；禁止发布时不显示「添加资源」。
- 点赞：乐观更新 + 失败回滚 + 主题化提示；图标实心/高亮，已点赞一眼可见。

### 词条页「补丁资源下载」标签页

- 与网页一致：只有 moyu 返回补丁资源时才显示该标签页；
- 只读卡片：名称、类型/体积/平台/语言/AI 模型/存储方式、下载数、
  备注（3 行截断）、发布者与更新时间；
- 「前往下载页面」打开 moyu 网页（不在站内下载）。
