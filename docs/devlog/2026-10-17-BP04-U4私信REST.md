# 2026-10-17 · BP-04 / U4 私信基础（REST）

## 本批交付

按 `蓝图集/BP-04-用户中心与消息域.md` 的 U4 范围，把私信从「跳网页」补成可用的 App 内会话：
会话列表、历史消息、发送文本/图片、引用回复、48 小时编辑、删除/撤回、已读、举报、
消息请求与聊天设置。实时通道（Centrifugo）与表情回应/置顶留给 U5。

### core（接口层）

- 新增 `ChatApi`（站点代理 `/api/v1/chat/`）：
  - `GET /chat/state`、`GET /chat/conversations?folder=inbox|requests|archive`、
    `GET /chat/conversations/{id}`；
  - `GET /chat/conversations/{id}/messages`（`before_seq` / `after_seq` / `around_seq`、`limit`）；
  - `POST /chat/conversations/{id}/messages`（`client_message_id` 幂等键、`reply_to_seq`、
    `media`）、`PATCH /chat/messages/{id}`（48h 内编辑）；
  - `POST /chat/conversations/{id}/messages/delete`（`seqs` + `for_everyone`）、
    `POST /chat/conversations/{id}/read`（`max_seq`）；
  - `POST /chat/conversations/{id}/accept`、`PATCH /chat/conversations/{id}/me`
    （归档/标未读/静音/置顶）、`POST /chat/conversations/{id}/clear-history`；
  - `POST /chat/messages/{id}/report`；
  - `GET/PATCH /chat/settings`（`allow_incoming`、`accept_requests`、`allow_group_invites`）；
  - `PUT /chat/direct/{user_id}`（打开/创建与某人的会话）、
    `POST /chat/images`（multipart 上传聊天图片）。
- 新增模型 `model/Chat.kt`：消息/回复引用/图片/用户/会话/会话状态/消息页/设置/已读/删除；
  `ChatConversation.folder` 按「未接受 → 消息请求、已归档 → 归档、其余 → 收件箱」归类，
  与网页 `chatModel.ts` 一致。
- `ChatApiTest` 9 项：状态与设置、会话列表与用户合并、文件夹归属、历史分页、发送请求体
  （幂等键/引用/图片）、编辑、删除与已读、接受/清空/举报/设置、打开会话与图片上传。

### app（界面层）

- **私信入口**：「消息」页私信一栏显示未读私信数；用户主页「更多」菜单新增「发私信」
  （打开或创建与对方的会话）。
- **会话列表**：全部 / 消息请求（带数量）/ 已归档 三个分区；头像、昵称、最后一条消息预览
  （自己的显示「你：」）、未读数/标为未读标记、时间；支持刷新与加载更多。
- **会话页**：
  - 历史消息（默认最新 50 条，可加载更早）；打开时自动标记已读；
  - 发送文本（≤4096 字）与图片（选择图片 → 上传 → 发送，单张，≤10 MiB）；
  - 长按消息：回复（引用整条消息）、复制文字、编辑（自己的纯文字消息且 48 小时内）、
    删除（自己的可选「同时为对方删除」）、举报（六类原因 + 补充说明）；
  - 会话菜单：标为未读、归档/移出归档、清空聊天记录（仅自己）、私信设置；
  - 消息请求：顶部接受 / 删除条；接受后转为正常会话，删除即清空并移除此会话；
  - 没有实时通道，页面提供手动刷新；发送后可下拉回看历史。
- **私信设置**：谁的私信直接进入对话列表（所有人/我关注的人/没有人）、是否接收消息请求；
  乐观更新、失败回滚（与网页 `/chat/settings` 相同范围）。

## 未验证 / 待办

- **没有真实会话可用**：驾驶员账号当前无任何私信，会话列表、历史消息、气泡布局、
  发送/编辑/删除/举报/接受请求只能等有真实会话后走查。
- **所有写操作未由我执行**：打开会话、发消息、发图、编辑、删除、举报、接受请求、
  设置保存。需要驾驶员自测或明确点名后验证。
- 实时更新属于 U5：当前没有 WebSocket / updates 轮询，对方新消息需手动刷新。
- 富文本只按纯文本展示与发送：不解析 `entities`（@提及、链接、加粗等），
  也不支持网页的局部引用（`reply_quote`）；群聊只显示标题与消息，没有成员管理。
- 图片按内容寻址 CDN 的 hash 规则拼接（`/{h0:2}/{h2:4}/{hash}.webp`），
  服务端下发 `url` 时优先用它。
