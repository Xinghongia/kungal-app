# 2026-10-18 · BP-05 U3 + U4 题库浏览/答题与出题（0.8.0）

## 背景

Galgame 页「题库」与发布页「发布 Galgame 习题」此前都是占位入口，作品词条的
「题库」标签也写着「将在 BP-05 接入」。本批把题库的读、答、写全部做成原生：
列表筛选、题目详情、作答与解析、收藏、质量评分、作答记录、评论墙，以及出题与编辑。

## 接口（2026-10-17 OpenAPI + 匿名探测，样本在 `research/probe/2026-10-17/bp05/`）

- `GET /quizzes`：`page/limit/work_id/author_id/quiz_type/quiz_category/difficulty/
  spoiler_level/include_nsfw/sort`；`QuizSort` 16 个组合
  （`bumped_at/created/view/view_1d/view_7d/view_30d/difficulty/answer_count × asc|desc`）。
- `GET /quizzes/{id}`：题干/描述 `ContentDocument`、选项、`solution`（仅已作答/作者可见）、
  作品、`viewer{has_answered,answer,has_favorited,quality_rating,can_edit,can_delete}`。
- `POST /quizzes/{id}/answers`（`Idempotency-Key` 必填）：单选/多选 `choice_indexes`，
  判断 `is_statement_true`；403 `SELF_ANSWER_FORBIDDEN`、409 `ALREADY_EXISTS`。
- `GET /quizzes/{id}/answers`：游标 20/页，未解锁时 `submission/is_correct` 为空。
- `PUT|DELETE /quizzes/{id}/favorite`、`PUT /quizzes/{id}/quality-rating {rating:1-10}`
  （未作答 403 `QUIZ_ANSWER_REQUIRED`）。
- `GET /quizzes/{id}/source`（仅 can_edit）、`POST /quizzes`（`Idempotency-Key`）、
  `PATCH /quizzes/{id}`、`DELETE /quizzes/{id}`。
- `GET /me/answered-quizzes`：我的答题（页码分页）。
- 评论墙 `subject_type=galgame_quiz`；剧透或隐藏作品且未作答时列表 403，
  网页提示「作答后即可查看并参与讨论」。

## 实现

### core

- 新增 `QuizDetail / QuizViewer / QuizAnswer / QuizSolution / QuizSubmission /
  QuizAnswerResult / QuizAnswerPage / QuizEngagement / QuizQuality / QuizSource /
  QuizCreate / QuizPatch` 等模型；`QuizSummary` 补上 `bumped_at / updated_at / viewer`。
- 新增 `QuizApi`：列表、详情、作答、作答记录、收藏、质量评分、源数据、出题、编辑、删除、
  我的答题。出题与作答带幂等键；编辑 PATCH 只发送非空字段。

### app（U3 浏览与答题）

- `/galgame-quiz` 题库列表：全部题库 / 我的答题（登录）；
  分类 / 题型 / 难度 / 排序字段 + 升降序（底部面板筛选，与资料库样式一致）；
  50/页页码分页；条目显示作答状态圆点、题干、作者、时间、题型/分类/剧透/浏览/作答/
  收藏/评论与难度、正确率。
- `/galgame-quiz/{id}` 题目详情：
  - 题型/难度/分类/剧透、关联作品（可点进词条）或「作答后揭晓」；
  - 单选/多选（卡片选项）与判断题（正确/错误大按钮）作答，提交后展示对错、
    正确选项、你的选择、解析；
  - 收藏、质量评分 1–10（仅已作答）、作答统计、可展开的作答记录（20/次加载更多）；
  - 剧透/隐藏作品且未作答时，评论墙显示「作答后即可查看并参与讨论」；
  - 作者/有权限者可从右上角菜单编辑或删除（二次确认）。
  - 重复作答按网页口径重载题目；作者自答等错误如实提示。
- 作品词条「题库」标签：本作相关题目 12/页 + 出题入口（未登录先登录）。
- 用户主页题库标签：出题/答题条目改为进原生题目页。
- 站内路径 `/galgame-quiz`、`/galgame-quiz/{id}`、`/edit/galgame/quiz` 与通知路径接通。

### app（U4 出题与编辑）

- `/galgame-quiz/create?workId=` 与 `/galgame-quiz/edit/{id}`：
  - 题型（编辑时不可改）、题干（≤200，支持 `||剧透||`）、描述 Markdown（≤20000）；
  - 选项 2–20 个、各 ≤200 字、不重复；单选唯一正确 / 多选至少一个；判断题选正确或错误；
  - 分类、难度 1–10、剧透等级、解析（≤2000，可选）；
  - 关联作品：搜索作品名添加（最多 20 部，已选可移除）、隐藏关联作品开关；
  - 校验规则与网页一致；保存失败如实提示，编辑保存后返回题目页。

## 未验证与已知边界

- 未做真机点击走查：题库筛选、作答提交、收藏、质量评分、作答记录加载、评论墙门禁、
  出题与编辑表单需驾驶员确认；
- 真实写操作（作答、收藏、评分、出题、编辑、删除）未在驾驶员账号执行，需驾驶员明确同意；
- 题目描述/解析的 Markdown 输入没有富文本工具栏（与话题编辑器一致，直接编辑源文）；
- 描述里上传线索图片依赖现有图片上传管线，本批未在题目编辑器内单独接入上传按钮；
- 题库的「我的答题」使用 `/me/answered-quizzes`，不显示作答时间（接口不返回）。
