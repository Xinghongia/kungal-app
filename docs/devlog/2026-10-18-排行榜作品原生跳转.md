# 2026-10-18 · 排行榜 Galgame 条目改为原生跳转（0.8.16）

## 背景

驾驶员实机反馈：排行榜 → Galgame 榜单，点击条目会跳浏览器，而不是在 App 内打开词条。

## 根因

`RankingScreen` 的作品榜回调只有 `onOpenWeb`，点击时拼了
`https://www.kungal.com/galgame/{id}` 交给浏览器打开。App 早已有原生词条页
（`Routes.galgameWork`），只是排行榜这一处没有接线。

## 改动

- `ui/ranking/RankingScreen.kt`：`onOpenWeb: (String) -> Unit` 改为
  `onOpenWork: (String) -> Unit`，作品榜点击传作品 id；
- `ui/AppNav.kt`：排行榜调用点改为 `nav.navigate(Routes.galgameWork(id))`。

## 证据

- `:core:test` 220 项、`:app:testDebugUnitTest` 138 项，合计 **358 项全绿**；
- `assembleRelease` 通过；版本 `0.8.15/code 44 → 0.8.16/code 45`，
  `USER_AGENT` 同步为 `kungal-app/0.8.16 (Android)`；
- 正式签名 APK 已覆盖安装（0.8.16/code 45），启动冒烟无崩溃（pid 25420）。

## 未验证 / 说明

- 排行榜三个榜单（用户 / 话题 / Galgame）的点击跳转需驾驶员在真机逐一确认；
- 本轮还顺带排查了其他仍走浏览器的作品入口（用户主页的作品 / 评分 / 资源列表
  目前仍跳网页），属于后续补齐项，未在本批改动。
