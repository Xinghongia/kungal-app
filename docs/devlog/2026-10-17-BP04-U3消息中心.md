# 2026-10-17 · BP-04 / U3 消息中心

## 本批交付

按 `蓝图集/BP-04-用户中心与消息域.md` 的 U3 范围，把「消息」页从占位改成可用的消息中心：
通知列表、已静音分区、通知偏好、关注的评论区，以及消息 tab 未读角标。

### core（接口层）

- 新增 `NotificationApi`：
  - 通知列表 `GET /me/notifications`（游标、`is_muted` 分区、`notification_type` 筛选）；
  - 未读汇总 `GET /me/notifications/summary`（未静音/已静音/私信未读）；
  - 已读标记 `PUT /me/notifications/read-marker`（`up_to_id` + `is_muted`）；
  - 单条删除 `DELETE /me/notifications/{id}`（204）；
  - 通知偏好 `GET /me/notification-preferences`、单类型静音/取消
    `PUT|DELETE /me/notification-preferences/muted-types/{type}`；
  - 关注墙 `GET /me/walls`、状态/关注/取关/已读
    `/me/walls/{subject_type}/{subject_id}[/follow|/read-marker]`。
- 新增模型 `model/Notification.kt`（`Notification`/`NotificationSummary`/`NotificationPreferences`/
  `NotificationReadMarker`/`WebsiteSummary`/`FollowedWall`/`WallState`）。
  汇总模型带 `badgeCount`：未静音通知 + 未静音时的未读私信。
- `NotificationApiTest` 9 项：列表查询组合、默认分区、汇总与角标、私信静音、已读请求体、
  删除、偏好静音/取消、关注墙解析、关注/取关方法。

### app（界面层）

- **消息页重排**：通知（含最新摘要与未读数）、已静音的消息、通知设置；关注分组：
  我订阅的话题、关注的评论区、关注动态；私信暂以「网页版」入口如实说明。
- **通知列表**：
  - 类型筛选片按通知偏好动态生成（未静音列表不显示已静音类型，反之亦然）；
  - 进入列表/翻页后，把已加载的未读通知按最大 id 标记已读（与网页 `read-marker` 行为一致）；
  - 单条删除有二次确认，删除后同步刷新角标；
  - 点击通知：`/topic/{id}` 与 `/user/{id}` 进 App，其余（商店、Galgame 等）打开网页原地址；
  - 折叠文案与网页一致（`等 N 人点赞了您`、`发表了 N 条新回复`、系统通知条数等）。
- **已静音的消息**：`is_muted=true` 分区，筛选片只列出被静音的类型；同样支持删除与跳转。
- **通知设置**：按网页分组（互动/关注/回复评论/内容审核/话题小程序/系统/私信）逐项开关；
  使用单类型 mute/unmute 接口，避免整体覆盖抹掉客户端不认识的新类型；失败回滚并提示。
- **关注的评论区**：列出已关注的墙（Galgame/评分/资源/题库/工具集/网站），显示标题与类型，
  可取消关注（确认后），点击打开网页原页面。新增关注仍需在网页详情页操作（客户端详情页未交付）。
- **未读角标**：底部「消息」显示未静音通知 + 未静音私信的未读数；登录、进出消息页、
  已读/删除、修改通知偏好后刷新。

## 驾驶员反馈修正（2026-10-17）

1. **用户主页切换到带二级菜单的标签时，头部卡片向下移动一点**：
   原因 = `PagedListContent` 默认 `contentPadding = PaddingValues(vertical = 8.dp)`，
   而「动态 / 关于 / 游玩时长」的列表顶部没有内边距；切到带筛选片（二级菜单）的标签时
   头部多出 8dp。同时二级筛选变化时列表会沿用旧的滚动位置。
   修正 = 分页列表顶部内边距改为 0（只保留底部 8dp），所有标签头部起点一致；
   `key` 变化（切换筛选/二级菜单）时滚动回列表顶部。
2. **空状态插图**：从官方 KunUI（`@kungal/ui-vue` 2.57.1）提取 `KUN_NULL_IMAGE`，
   放入 `app/src/main/res/drawable-nodpi/kun_empty.webp`，新增通用 `EmptyBox` 组件；
   用户主页各内容标签、动态概览、游玩时长与分页列表的空态统一为「插图 + 文案」。
   注意：该插图来自官方 UI 库（AGPL-3.0-only），本仓库代码仍是 MIT；对外发布前需在
   README/NOTICE 写明来源与许可，或向站长确认授权。
3. **资料设置隐私开关反应慢、互相卡住**：
   原因 = 三个开关共用一个 `privacyBusy`，任一请求期间三个开关全部禁用；
   且界面要等服务器返回后才切换，网络往返期间看起来「点了没反应」。
   修正 = 每个开关独立 busy 标志 + 乐观更新：点击立即切换，只有本开关在保存期间不可再点；
   失败时回滚该开关并提示，其他开关不受影响。
