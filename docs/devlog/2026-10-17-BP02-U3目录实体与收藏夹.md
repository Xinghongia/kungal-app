# 2026-10-17 · BP-02 U3 目录实体与收藏夹

## 本批做了什么

词条里指向的会社 / 标签 / 角色 / Staff / 引擎 / 系列 / 特质全部变成原生页面，
并补齐收藏夹详情与管理；站内链接统一由 App 内分发，不再一律跳网页。

### 目录实体

- 标签：列表（搜索）、详情（简介、上级/子标签、阻断计数）、该标签的作品列表；
  登录后可屏蔽标签（含子标签 / 仅此标签两种模式）或取消屏蔽。
- 会社：列表（搜索 + 会社类型筛选）、详情（Logo、别名、简介、官网等链接、
  会社关系：母公司/子公司/品牌/前身等）、作品列表（可按「仅自身 / 仅品牌」筛选）。
- 引擎：列表（搜索）、详情、作品列表。
- 系列：列表（搜索，含样例作品封面）、详情（简介、样例作品）、作品列表。
- 角色：列表（搜索、性别、排序；支持从特质进入时按特质筛选）、详情
  （立绘/头像可看大图、简介、链接、特质、出演作品 + 声优，游标分页）。
- 制作人员（Staff）：详情（照片、性别、生日、其他名义、简介、链接、参与作品 + 职务 + 角色）。
- 特质：根分组列表（搜索）、详情（说明、别名、父子特质、相关角色列表）。
- 所有实体作品列表共用同一套单值筛选（排序 + 升降序、平台/模拟器、语言、资源类型、
  游戏类型、会社作品来源），与网页实体页的筛选面一致。

### 收藏夹

- 收藏夹详情：标题/描述/可见性/归属人/封面预览、作品列表与四种排序
  （收藏时间升降序、发售日期升降序）；作者可编辑（标题/描述/公开或私密）、
  删除收藏夹、把作品移出收藏夹。
- 「我的收藏夹」页：列出全部收藏夹（含私密）、新建收藏夹；入口加在「我的」页。
- 个人主页收藏夹、作品行、话题等站内链接统一走分发器：已实现的路径进 App，
  未实现/外部链接交浏览器。

### 导航

- Galgame 入口的「会社 / 标签 / 角色 / 引擎 / 系列」接原生列表；
  词条内的标签/会社/系列/引擎/角色/Staff 链接接原生详情；
  通知与个人主页里的 `/galgame/{id}`、`/collection/{id}` 也进原生页面。

## 核心接口

- `GalgameEntityApi`：标签（列表/详情/后代/作品/屏蔽读写）、会社（列表/详情/关系图/作品）、
  引擎（列表/详情/作品）、系列（列表/详情/作品）、角色（列表/详情/出演）、
  Staff（搜索/详情/参与作品）、特质（列表/详情）。
- `CollectionApi` 扩充：收藏夹详情、作品列表（排序）、修改（PATCH）、删除、
  我的收藏夹（含 work_id 过滤）。
- 新增实体模型约 30 个（Tag/Company/Graph/Character/Credit/Trait/Collection 等）。

## 已知边界

- 会社关系图以关系列表呈现（母公司/子公司/品牌/前身等，可点进会社），
  未做网页同款的可拖拽关系画布。
- 标签屏蔽管理只在标签详情页（屏蔽/取消屏蔽）；没有单独的「已屏蔽标签」总览页。
- 评分列表/详情（U4）、编辑与投稿（U5/U6）仍为网页出口。
