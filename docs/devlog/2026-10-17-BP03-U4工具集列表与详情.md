# 2026-10-17 · BP-03 U4 工具集列表与详情（0.5.3）

## 本批做了什么

### 工具集列表（`/toolset` → 原生）

- 搜索（250ms 防抖）、类型 / 平台 / 版本筛选、排序字段 + 升降序、24/页触底加载、
  下拉刷新、重置筛选；筛选胶囊复用资料库同款（点开底部面板）。
- 卡片：标题、类型 · 版本、平均实用性、平台/语言/别名 chip、作者、
  浏览/下载/评论数。
- 发现页「Gal 工具资源」入口、站内路径 `/toolset` 进 App。

### 工具集详情（`/toolset/{id}` → 原生）

- 标题、版本/平台/语言/类型 chip、Markdown 介绍；
- 实用性分布横向柱状图（1–5 星人数，本人评的那一档高亮）、平均分、星条评分（点击即评分）；
- 作者、浏览/下载数、主页/项目链接、别名；
- 收藏（带数量，选中态红底红心）、订阅评论（`/me/walls/toolset/{id}`）、
  上传/添加资源、修改/删除（有权限时，删除扣 3 萌萌点需确认）；
- 工具资源列表：对象存储/自定义链接标识、体积、下载人数、
  获取链接（file 返回预签名 URL 并显示有效期；link 返回原链接）、复制链接、
  提取码/解压码一键复制、备注展开、发布者；有权限时编辑/删除；
- 评论墙（`subject_type=toolset`，maxLength 5000）；
- 工具资源发布/编辑弹窗：链接型完整可用（分享文本一键识别、体积校验），
  文件上传在 U6 接入前给出明确提示；
- 用户主页「工具集」标签条目改跳原生详情。

### 工具集创建/编辑（U5 提前并入）

  名称、类型、版本、平台、语言、Markdown 简介、主页链接、别名；
